# Changesets

Каждое изменение, которое увидят пользователи пакетов, сопровождается файлом-описанием в этой папке. Создать его:

```bash
pnpm changeset
```

Выберите пакеты, тип изменения (`patch` — исправление, `minor` — новая возможность, `major` — несовместимое изменение) и
напишите одну-две фразы для CHANGELOG. Все пакеты `@inkbrick/*` версионируются вместе (`fixed`): версия у них всегда одна.

Выпуск: в PR `develop` → `master` команда `pnpm version-packages` поднимает версии по накопленным описаниям и пишет
`CHANGELOG.md` каждого пакета; тег `vX.Y.Z` на `master` запускает публикацию (`.github/workflows/release.yml`). Подробнее —
в `CONTRIBUTING.md`, раздел «Versions and releases».
