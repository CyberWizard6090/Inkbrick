# Экспорт документа

Адаптеры работают поверх `Document` из `@inkbrick/document` и не зависят от React и DOM — их можно вызывать
на сервере и в сборочных скриптах.

```ts
import { toMarkdown, toHtml, toPlainText, exportDocument } from '@inkbrick/document';

toMarkdown(editor.document, { schema: editor.schema });
toHtml(editor.document);
toPlainText(editor.document, { title: false });
exportDocument(editor.document, 'markdown'); // 'text' | 'markdown' | 'html'
```

## Параметры

| Параметр | По умолчанию | Назначение                                                                                                   |
| -------- | ------------ | ------------------------------------------------------------------------------------------------------------ |
| `schema` | —            | Реестр схем: контейнерами считаются блоки с ролью `root`/`hub` (в том числе свои). Без него — `page`, `note` |
| `from`   | корень       | Экспортировать поддерево этого блока                                                                         |
| `title`  | `true`       | Первой строкой вывести заголовок страницы (`props.title`); только при экспорте всего документа               |

## Как блоки выглядят в каждом формате

| Блок                | Markdown                                        | HTML                                                                    | Текст                  |
| ------------------- | ----------------------------------------------- | ----------------------------------------------------------------------- | ---------------------- |
| paragraph           | абзац                                           | `<p>` (+ `text-align`)                                                  | абзац                  |
| heading             | `#`…`######`                                    | `<h1>`…`<h6>`                                                           | строка                 |
| list bullet/ordered | `- ` / `1. `, вложенность — отступом            | `<ul>` / `<ol>`, вложенные внутри `<li>`                                | `- ` / `1. `, отступ 2 |
| list todo           | `- [ ]` / `- [x]`                               | `<input type="checkbox" disabled>`                                      | `[ ]` / `[x]`          |
| quote               | `> `                                            | `<blockquote>`                                                          | строка                 |
| callout             | `> [!NOTE]` (по тону: NOTE/WARNING/TIP/CAUTION) | `<aside data-callout="тон">`                                            | строка                 |
| code                | ограждение из обратных кавычек с языком         | `<pre><code class="language-…">`                                        | как есть               |
| divider             | `---`                                           | `<hr>`                                                                  | `---`                  |
| image               | `![alt](src)` + подпись курсивом                | `<figure><img><figcaption>`                                             | подпись или alt        |
| formula             | `$$` … `$$`; встроенная — `$код$`               | `<div class="math display">`, встроенная — `<span class="math inline">` | исходный LaTeX         |

Инлайн-форматирование: жирный, курсив, зачёркнутый, код, ссылка. Подчёркивание в Markdown выводится тегом `<u>`;
цвета отбрасываются. Блоки неизвестных типов выводятся как текст.

## Безопасность

- Весь текст и значения атрибутов экранируются (HTML) или маскируются (Markdown: `\ * _ [ ] < > ~ |`, символы в начале строки,
  ограждение кода длиннее любой серии кавычек внутри).
- Ссылки пропускаются через `isSafeUrl`, картинки — через `isSafeImageUrl`; небезопасные (`javascript:`, `data:` не-картинки, SVG)
  выводятся только текстом.
- В HTML допустимы только значения `text-align` и тон callout из белых списков.
