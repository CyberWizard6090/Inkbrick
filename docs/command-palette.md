# Палитра команд

Окно поиска по действиям редактора и приложения: Ctrl/Cmd+Shift+P открывает его, стрелки выбирают, Enter выполняет, Esc
закрывает. Ctrl+P браузер отдаёт печати, поэтому палитра на Ctrl+Shift+P (как в VS Code); другую комбинацию задаёт своя
привязка с `id: 'palette.open'` (см. [клавиши](keymap.md)).

Палитра не входит в набор по умолчанию. Клавиши подключаются в провайдере, окно кладётся рядом с документом:

```tsx
import { EditorProvider, DocumentView, CommandPalette, commandPalette } from '@inkbrick/react';

<EditorProvider editor={editor} keymap={commandPalette.keymap}>
  <CommandPalette commands={[{ id: 'app.save', title: 'Save', shortcut: 'Mod-S', run: save }]} />
  <DocumentView />
</EditorProvider>;
```

Если у провайдера уже есть свои клавиши: `keymap={[...commandPalette.keymap, ...mine]}`.

## Что в списке

Встроенные команды (отключаются `builtin={false}`) строятся при каждом открытии и зависят от выделения и блока:

| Раздел       | Команды                                                                                                 |
| ------------ | ------------------------------------------------------------------------------------------------------- |
| Документ     | Отменить и вернуть (только когда есть что отменять)                                                     |
| Формат       | Жирный, курсив, подчёркнутый, зачёркнутый, код: только при выделенном тексте и вне кода                 |
| Превратить в | Каждый пункт slash-меню, в который текущий блок можно превратить (движок проверяет схему и вложенность) |
| Вставить     | Каждый пункт slash-меню как новый блок после текущего                                                   |

Пункты «Превратить в» и «Вставить» берутся из `slashItems` провайдера, поэтому свои блоки приложения появляются в палитре сами.
В режиме только чтения всё, что меняет документ, скрыто.

Команды поиска (`findReplace.commands`) и свои передаются в `commands`; команда с тем же `id`, что у встроенной, заменяет её.

## Своя команда

```ts
interface PaletteCommand {
  id: string;
  title: string | ((t: TFunction) => string); // готовый текст или функция от перевода
  description?: string | ((t) => string);
  group?: string | ((t) => string); // заголовок раздела; без него команда стоит в конце
  keywords?: string[]; // по ним тоже ищется
  shortcut?: string; // подсказка, например 'Mod-S' (показывается как Ctrl+S или ⌘S); привязки не создаёт
  icon?: ReactNode;
  when?: (context) => boolean; // false скрывает команду
  run: (context) => void;
}
```

`context` — `{ editor, view, t, readOnly, selection }`. `selection` — выделение в документе **в момент открытия**: фокус
уходит в строку поиска, поэтому палитра запоминает его и перед `run` возвращает в документ. Без запроса команды идут разделами
в порядке появления; с запросом — по релевантности (название, начало слова, ключевые слова, раздел).

## Из кода

`useCommandPalette()` возвращает `controller` (`open()`, `close()`, `toggle()`) и `state`. Это нужно, например, для кнопки
«Команды» в интерфейсе приложения или чтобы открыть палитру в режиме только чтения, где клавиши редактора не работают.

## Доступность и оформление

Окно — `role="dialog"`, строка поиска — `combobox` со ссылкой на `listbox` и на выбранный пункт (`aria-activedescendant`),
фокус остаётся в окне (Tab его не покидает), Esc возвращает его в документ. Части разметки: `data-inkbrick-ui="palette"`
и `"palette-backdrop"`, внутри `data-inkbrick-part="query | list | group | option | title | description | shortcut | empty"`.
Стили в слое `@layer` через `:where()`, переопределяются без повышения специфичности.
