# Выбор и перенос нескольких блоков

Блоки можно выбрать целиком, не выделяя текст, и работать с ними как с одним: удалить, дублировать, скопировать, перенести.
Выбор — это соседи одного уровня (абзацы, пункты списка, блоки внутри toggle или колонки), подряд или вразброс. Он не входит
в документ и не попадает в историю; действия над выбранными блоками — один шаг undo.

Выбранный блок выглядит так: сплошная полупрозрачная голубая заливка на всю ширину блока со скруглением, без рамки и
теней. Она лежит поверх собственного фона блока (цвет фона не пропадает) и одинакова в светлой и тёмной темах.

## Как выбрать

| Жест                                            | Результат                                                                                                                                                                                                             |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Esc` в блоке                                   | Выбирает блок под кареткой; ячейка и строка таблицы выбирают саму таблицу                                                                                                                                             |
| `Esc` при выделенном тексте в нескольких блоках | Выбирает весь ряд блоков, который охватывает выделение                                                                                                                                                                |
| `Ctrl/Cmd+A`                                    | Первое нажатие выделяет весь текст блока, следующее — выбирает все блоки документа (верхнего уровня); если выбор уже внутри toggle или колонки, он растёт уровень за уровнем (в пустом блоке — сразу все блоки)       |
| `Shift+↓` / `Shift+↑`                           | Расширяет выбор от якоря на соседа; обратное движение сужает (блоки, выбранные вразброс, остаются)                                                                                                                    |
| `↓` / `↑`                                       | Переносит выбор на соседа (один блок)                                                                                                                                                                                 |
| `Shift+клик` по ручке или по блоку              | Расширяет выбор от якоря до кликнутого блока (диапазон). Без выбора якорь — блок под кареткой                                                                                                                         |
| `Ctrl/Cmd+клик` по ручке                        | Добавляет блок в выбор или убирает его из выбора; выбор может быть несвязным                                                                                                                                          |
| Рамка мышью в поле за краем документа           | Выбирает блоки верхнего уровня, которых касается рамка, по мере протяжки; у края окна документ прокручивается сам. Протягивание внутри полей рядом с текстом по-прежнему выделяет текст, клик в поле — ставит каретку |
| `Esc` ещё раз / `Enter`                         | Снимает выбор; каретка в конец (`Esc`) или в начало (`Enter`) блока                                                                                                                                                   |
| Клик в документе или на странице вне редактора  | Снимает выбор (меню и панели редактора выбор не снимают)                                                                                                                                                              |

Рамка рисуется там, где есть поле вне корня редактора: страница с `data-inkbrick-surface` на обёртке шире документа (как в
песочнице, [выделение](selection.md)). Начало рамки привязано к блоку, а не к координатам: блок, с которого начали, остаётся
началом, пока документ прокручивается, в том числе в виртуальном рендере (50 000 блоков). Выбор обновляется раз в кадр. `Esc` не
выбирает блок, пока открыто меню `/`, контекстное меню, меню блока, панель поиска или палитра команд, и пока выделены ячейки
таблицы: у них свой `Esc`.

## Что можно сделать

| Действие              | Клавиши                                  | Примечание                                                                                                                                                                       |
| --------------------- | ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Удалить               | `Delete`, `Backspace`                    | Блоки, которые нельзя удалить (закреплённые), остаются; если удалены все — остаётся пустой абзац                                                                                 |
| Дублировать           | `Ctrl/Cmd+D`                             | Копии идут сразу после последнего выбранного, в том же порядке; выбираются копии. Без выбора дублирует блок под кареткой                                                         |
| Сдвинуть вверх и вниз | `Ctrl/Cmd+Shift+↑` / `↓`                 | На одну позицию; порядок выбранных сохраняется (несвязный выбор сдвигается блок за блоком). Без выбора сдвигает блок под кареткой                                                |
| Копировать, вырезать  | `Ctrl/Cmd+C`, `Ctrl/Cmd+X`               | Блоки целиком, со вложенными: в буфер идёт то же, что при выделении от начала первого до конца последнего; при выборе вразброс — выбранные блоки подряд, без тех, что между ними |
| Перенести мышью       | Перетаскивание ручки любого из выбранных | Переносится весь выбор одним жестом, под курсором видна линия вставки «до» или «после» цели, один шаг undo; в колонки (к краю) переносится только один блок                      |
| Меню блока            | Ручка → меню на выбранном блоке          | «Дублировать», «Вверх», «Вниз», «Удалить», «Превратить в» и «Фон» относятся ко всему ряду                                                                                        |

**«Превратить в» и «Фон» для ряда.** Откройте меню ручкой любого из выбранных блоков: пункт «Превратить в» или цвет фона применяется
ко всем выбранным блокам сразу и откатывается одним undo. Действие касается только тех блоков, к которым применимо: блоки, которые
нельзя превратить в этот тип (таблица, изображение) или у которых нет фона (код, формула, таблица), остаются как были; если
пункт не подходит ни одному блоку, его нет в меню (как и строки цветов, когда фона нет ни у одного). В тип без текста (разделитель,
таблица) превращается только один блок, поэтому для ряда этих пунктов нет. Отмеченный цвет в строке показан, когда он общий у
всех блоков с фоном. После действия выбор остаётся, фокус возвращается в документ. Палитра команд ([палитра](command-palette.md)),
открытая при выбранном ряде, тоже предлагает «Превратить в …» для всех выбранных блоков. Меню блока вне выбора действует только на
свой блок.

Набор текста, пока блоки выбраны, ничего не вставляет (клавиши игнорируются), вставка из буфера тоже не поддерживается: сначала
снимите выбор. В режиме только чтения выбор блоков не работает (клавиши редактора там отключены).

## Из кода

`view.picked` (`EditorView`): `getState()` → `{ ids, anchor, focus }` (`ids` — в порядке документа, соседи одного родителя, могут идти
не подряд), `set(ids, anchor?, focus?)`, `clear()`, `has(id)`, `subscribe`. Блок с выбором получает атрибут `data-picked`: его ставит
сам `view.picked` одним проходом по нарисованным блокам (блоки не подписываются на выбор по отдельности, поэтому выбор тысяч
блоков не перерисовывает их); блок, появившийся при прокрутке, отмечает себя при монтировании. Стиль — в `@inkbrick/styles`
(`:where([data-picked])`, цвет заливки — токен `--inkbrick-picked-bg`, по умолчанию `rgba(35, 131, 227, 0.14)`); пока выбрано, у корня
стоит `data-picking` (скрывает каретку). Действия — в `pick/actions`: выбор, расширение (`extendPick`), диапазон (`pickRangeTo`),
добавление и снятие блока (`togglePick`), все блоки уровня (`pickAll`), `deleteBlocks`, `duplicateBlocks`, `moveBlocks`,
`convertBlocks`/`convertibleIn` (превращение), `setBackgrounds`/`backgroundTargets` (фон), `pickedFragment`. Привязки — `pickKeymap`
(ids `pick.start`, `pick.selectAll`, `pick.exit`, `pick.delete`, `pick.duplicate`, `pick.moveUp` и т. д.): их можно заменить или
отключить через `keymap` провайдера, как любые стандартные ([клавиши](keymap.md)). Встроенный перенос (`useBlockDrag`) тоже
переносит весь выбор: `move(blockId, …)` для блока из выбора двигает все.

## Производительность

Выбор рассчитан на документы в десятки тысяч блоков (виртуальный рендерер). Рамка находит блоки по границам нарисованных строк
бинарным поиском и обновляется раз в кадр, а не на каждое событие мыши; отметка `data-picked` не требует ни подписок, ни
поиска по документу для каждого блока. Замеры до и после — в описании PR (`fix/block-picking`); регрессию стерегут тесты на
число обращений к DOM (`tests/block-pick-ctrl-a.test.tsx`, `tests/E2E/large-document.spec.ts`).

## Ограничения

- Выбор — только соседи одного родителя: выбрать блок из одного toggle и блок снаружи нельзя (Ctrl/Cmd+клик по блоку из другой ветки
  начинает выбор заново).
- Рамка выбирает блоки верхнего уровня заметки; блоки внутри колонок и toggle выбираются клавишами и кликами по ручкам.
- «Превратить в» для ряда работает только для текстовых типов; фон палитра команд не предлагает (только меню блока).
- Двойное `Ctrl/Cmd+A` выбирает блоки, а не выделяет текст всего документа: чтобы выделить текст документа, используйте контекстное меню
  «Выделить всё» или протяжку мышью.
