# Выбор и перенос нескольких блоков

Блоки можно выбрать целиком, не выделяя текст, и работать с ними как с одним: удалить, дублировать, скопировать, перенести.
Выбор — это подряд идущие соседи одного уровня (абзацы, пункты списка, блоки внутри toggle или колонки). Он не входит в документ
и не попадает в историю; действия над выбранными блоками — один шаг undo.

## Как выбрать

| Жест                                            | Результат                                                                                                                                                  |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Esc` в блоке                                   | Выбирает блок под кареткой; ячейка и строка таблицы выбирают саму таблицу                                                                                  |
| `Esc` при выделенном тексте в нескольких блоках | Выбирает весь ряд блоков, который охватывает выделение                                                                                                     |
| `Shift+↓` / `Shift+↑`                           | Расширяет выбор от якоря на соседа; обратное движение сужает                                                                                               |
| `↓` / `↑`                                       | Переносит выбор на соседа (один блок)                                                                                                                      |
| Рамка мышью в поле за краем документа           | Выбирает блоки верхнего уровня, которых касается рамка. Протягивание внутри полей рядом с текстом по-прежнему выделяет текст, клик в поле — ставит каретку |
| `Esc` ещё раз / `Enter`                         | Снимает выбор; каретка в конец (`Esc`) или в начало (`Enter`) блока                                                                                        |
| Клик в документе                                | Снимает выбор                                                                                                                                              |

Рамка рисуется там, где есть поле вне корня редактора: страница с `data-inkbrick-surface` на обёртке шире документа (как в
песочнице, [выделение](selection.md)). `Esc` не выбирает блок, пока открыто меню `/`, контекстное меню, меню блока, панель поиска или
палитра команд, и пока выделены ячейки таблицы: у них свой `Esc`.

## Что можно сделать

| Действие              | Клавиши                                  | Примечание                                                                                                               |
| --------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Удалить               | `Delete`, `Backspace`                    | Блоки, которые нельзя удалить (закреплённые), остаются; если удалены все — остаётся пустой абзац                         |
| Дублировать           | `Ctrl/Cmd+D`                             | Копии идут сразу после последнего выбранного, в том же порядке; выбираются копии. Без выбора дублирует блок под кареткой |
| Сдвинуть вверх и вниз | `Ctrl/Cmd+Shift+↑` / `↓`                 | На одну позицию; порядок внутри ряда сохраняется. Без выбора сдвигает блок под кареткой                                  |
| Копировать, вырезать  | `Ctrl/Cmd+C`, `Ctrl/Cmd+X`               | Блоки целиком, со вложенными: в буфер идёт то же, что при выделении от начала первого до конца последнего                |
| Перенести мышью       | Перетаскивание ручки любого из выбранных | Переносится весь ряд одним жестом; «до» или «после» цели; в колонки (к краю) переносится только один блок                |
| Меню блока            | Ручка → меню на выбранном блоке          | «Дублировать», «Вверх», «Вниз», «Удалить» относятся ко всему ряду                                                        |

Набор текста, пока блоки выбраны, ничего не вставляет (клавиши игнорируются), вставка из буфера тоже не поддерживается: сначала
снимите выбор. В режиме только чтения выбор блоков не работает (клавиши редактора там отключены).

## Из кода

`view.picked` (`EditorView`): `getState()` → `{ ids, anchor, focus }`, `set(ids, anchor?, focus?)`, `clear()`, `has(id)`,
`subscribe`. Блок с выбором получает атрибут `data-picked` (стиль в `@inkbrick/styles`, переопределяется через `:where()`),
пока выбрано, у корня стоит `data-picking` (скрывает каретку). Действия — в `pick/actions`: выбор, расширение, `deleteBlocks`,
`duplicateBlocks`, `moveBlocks`, `pickedFragment`. Привязки — `pickKeymap` (ids `pick.start`, `pick.exit`, `pick.delete`,
`pick.duplicate`, `pick.moveUp` и т. д.): их можно заменить или отключить через `keymap` провайдера, как любые стандартные
([клавиши](keymap.md)). Встроенный перенос (`useBlockDrag`) тоже переносит ряд: `move(blockId, …)` для блока из выбора двигает все.

## Ограничения

- Выбор только подряд идущих блоков одного родителя: выбрать блок из одного toggle и блок снаружи нельзя.
- Рамка выбирает блоки верхнего уровня заметки; блоки внутри колонок и toggle выбираются клавишами.
- «Превратить в» и «Фон» применяются к одному блоку: на весь ряд пока не распространяются.
