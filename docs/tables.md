# Таблицы

Таблица — три типа блоков: `block:table` → строки `block:table-row` → ячейки `block:table-cell`. Ячейка — обычный
текстовый блок, поэтому форматирование, выравнивание, undo и выделение работают в ней так же, как в абзаце.
В ячейке только текст: списки, картинки и объединённые ячейки не поддерживаются.

Готовы модель, команды движка, отрисовка в `@inkbrick/react`, клавиатура, управление мышью, буфер обмена, экспорт и отдельный
редактор таблицы (`<TableEditor>`).

## Подключение

Во встроенный набор блоков таблица не входит — редактору без таблиц её код не нужен. Один и тот же список
передаётся и редактору, и провайдеру:

```tsx
import { Editor } from '@inkbrick/engine';
import { EditorProvider, DocumentView, tableBlocks } from '@inkbrick/react';

const editor = new Editor({ blocks: tableBlocks });

<EditorProvider editor={editor} blocks={tableBlocks}>
  <DocumentView />
</EditorProvider>;
```

В slash-меню появляется пункт «Таблица» (`/table`, `/таблица`). Без React — только схемы и команды:
`tableBlocks` из `@inkbrick/engine`; только схемы (проверить снимок на сервере) —
`createSchemaRegistry(tableBlockSchemas)` из `@inkbrick/document`.

## В редакторе

| Действие                        | Результат                                                             |
| ------------------------------- | --------------------------------------------------------------------- |
| `Tab` / `Shift+Tab`             | следующая / предыдущая ячейка, по строкам; курсор — в конец её текста |
| `Tab` в последней ячейке        | новая строка в конце таблицы                                          |
| `Enter`                         | перевод строки внутри ячейки                                          |
| `Backspace` в начале ячейки     | ничего: ячейки не склеиваются                                         |
| клик по ячейке мимо текста      | курсор в этой ячейке, на строке клика                                 |
| выделение через несколько ячеек | `Delete` очищает их текст, форматирование применяется ко всем         |

Ручка блока, меню и перенос есть у таблицы целиком; у строк и ячеек своих ручек нет. В ячейках не открывается
slash-меню и не показывается подсказка про «/». Стрелки ходят по ячейкам средствами браузера.

Разметка — обычная `<table>` в прокручиваемой по горизонтали обёртке: `data-inkbrick-block="table"`
(`data-header`, если первая строка — заголовок; внутри часть `grid` и `<colgroup>` с ширинами столбцов),
`table-row` на `<tr>` и `table-cell` на `<td>` (`data-align`). Свой вид — обычным способом, через `components`.

## Управление мышью

Пока над таблицей мышь (или в ней каретка — так работает и клавиатура, и касание), рядом с ней рисуются элементы управления:

| Элемент                                       | Что делает                                                                                                         |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| полоска у левого края строки под курсором     | меню строки: вставить выше и ниже, переместить, сделать первую строку заголовком, удалить                          |
| полоска у верхнего края столбца под курсором  | меню столбца: вставить слева и справа, переместить, выровнять столбец, ширина по содержимому, удалить              |
| кнопка «+» справа и снизу                     | добавить столбец и строку в конец                                                                                  |
| тонкая зона на правой границе каждого столбца | потянуть — изменить ширину (виден предпросмотр, в историю попадает один шаг), двойной клик — ширина по содержимому |

Каждое действие — один шаг undo, после него каретка встаёт в подходящую ячейку. Меню — это слот `BlockMenu` (тот же вид, что у меню
ручки блока), так что своё меню блока подменяет и меню таблицы. Ширина столбца — от 40 до 1200 пикселей; стрелки влево и вправо на
сфокусированной зоне границы меняют её на 10. Размер таблицы ограничен теми же пределами, что и вставка (2000 ячеек, 50 столбцов):
у предела кнопки добавления отключаются. Элементы рисуются поверх документа (портал в `body`), а не внутри редактируемого корня,
поэтому в выделение и буфер обмена не попадают; в режиме только чтения их нет.

Разметка: `data-inkbrick-ui="table-controls"` с частями `row-grip`, `column-grip`, `add-row`, `add-column` и `resize`.

**Правый клик.** В ячейке контекстное меню получает под стандартными пунктами шесть своих: вставить строку выше и ниже,
удалить строку, вставить столбец слева и справа, удалить столбец — для строки и столбца, где стоит курсор. Это общая
возможность: у `defineBlock` есть поле `contextMenu(context) => ContextMenuItem[]`, пункты идут под разделителем
(`separatorBefore`).

**Закрепление.** В меню первой строки есть пункт «Закрепить первую строку», в меню первого столбца — «Закрепить первый
столбец» (props таблицы `freezeRow` и `freezeColumn`, по умолчанию выключены). Закреплённые строка и столбец остаются на виду при
прокрутке: у таблицы с закреплённой строкой появляется своя вертикальная прокрутка, высота ограничена переменной
`--inkbrick-table-frozen-height` (по умолчанию `min(70vh, 640px)`). Через буфер обмена и экспорт закрепление не передаётся.

## Выделение ячеек

Протяните мышью от одной ячейки к другой — выделится прямоугольник между ними. Расширить его можно `Shift+клик` и
`Shift+стрелками`; строку или столбец целиком выделяют пункты «Выделить строку» и «Выделить столбец» в их меню. Пока выделены
ячейки, выделенного текста в документе нет:

| Действие                             | Результат                                                                        |
| ------------------------------------ | -------------------------------------------------------------------------------- |
| `Delete`, `Backspace`                | текст выделенных ячеек очищается (один шаг undo), таблица и ячейки остаются      |
| `Ctrl/Cmd+C`, `Ctrl/Cmd+X`           | в буфер идёт таблица из выделенных ячеек (HTML, TSV, точный фрагмент); X очищает |
| `Ctrl/Cmd+V`                         | вставка начинается с верхней левой ячейки выделения                              |
| стрелка, `Esc`, символ, `Enter`, Tab | выделение снимается, курсор встаёт в ячейку                                      |
| щелчок вне выделения                 | выделение снимается                                                              |

Заголовком скопированная таблица остаётся, только если в выделение попала первая строка. Для кода: `tableRangeBetween`,
`tableRangeCells` и `tableRangeFragment(getBlock, tableId, range)` из `@inkbrick/engine`; у `EditorView` есть `cells` — текущее
выделение (`view.cells.get()`), на него можно подписаться.

## Создание

```ts
editor.dispatch({ type: 'insertBlock', payload: { flavour: 'block:table', afterId } });
editor.dispatch({ type: 'convertBlock', payload: { blockId, flavour: 'block:table' } });
```

Обе команды создают таблицу 3×3 одним шагом undo и возвращают позицию курсора в первой ячейке. `convertBlock`
ставит после таблицы пустой абзац. Props таблицы: `header` (первая строка — заголовок, по умолчанию `true`) и
`widths` — ширины столбцов в пикселях (`null` — по содержимому).

## Строки и столбцы

Количество и порядок строк и ячеек меняют только команды таблицы; `blockId` — id таблицы, номера — с нуля.

| Команда                                  | Что делает                                                     |
| ---------------------------------------- | -------------------------------------------------------------- |
| `insertTableRow` `{ index }`             | пустая строка на месте `index`; курсор — в её первую ячейку    |
| `deleteTableRow` `{ index }`             | удаляет строку; последнюю удалить нельзя                       |
| `moveTableRow` `{ from, to }`            | переносит строку                                               |
| `insertTableColumn` `{ index }`          | пустой столбец на месте `index`; курсор — в его верхнюю ячейку |
| `deleteTableColumn` `{ index }`          | удаляет столбец; последний удалить нельзя                      |
| `moveTableColumn` `{ from, to }`         | переносит столбец                                              |
| `setTableColumnWidth` `{ index, width }` | ширина столбца в пикселях; `null` — по содержимому             |

Каждая команда — один шаг undo; ширины столбцов переезжают вместе со столбцами. `editor.can(type, payload)`
отвечает, выполнится ли команда.

```ts
import { locateTableCell, tableCellAt, tableSize } from '@inkbrick/engine';

const getBlock = (id: string) => editor.document.getBlock(id);

locateTableCell(getBlock, cellId); // { tableId, row, column }
tableSize(getBlock, tableId); // { rows, columns }
tableCellAt(getBlock, tableId, 0, 2); // id ячейки
```

## Как ведут себя обычные команды

Строка и ячейка помечены в схеме `isolating: true` — это неделимые части таблицы:

- **Enter** в ячейке вставляет перевод строки и никогда не выходит из неё.
- **Backspace** в начале ячейки ничего не делает: ячейка не становится абзацем и не склеивается с соседней.
- **Удаление выделения**, у которого хотя бы одна граница в ячейке, очищает текст ячеек, а сетку не трогает.
  Обычные блоки, попавшие в выделение целиком, удаляются. Выделение, которое покрывает таблицу целиком
  (от абзаца до неё до абзаца после), удаляет её, как любой другой блок.
- **Вставка из буфера** в ячейку идёт текстом: блоки фрагмента становятся строками.
- `insertBlock`, `delete-block`, `moveBlock`, `duplicateBlock`, `convertBlock` для строк и ячеек не выполняются.
  Саму таблицу можно удалять, переносить и дублировать как обычный блок.

## Буфер обмена

**Копирование.** Выделение, которое задевает таблицу, кладёт в буфер таблицу, а не отдельные ячейки: `text/html` с `<table>`
(заголовок — в `<thead>`, выравнивание — `text-align`, ширины — `<colgroup>`), `text/plain` со строками, где ячейки разделены
табуляцией (ячейки с табуляцией, кавычками и переводами строк — в кавычках, RFC 4180: так их понимают Excel и Google Sheets), и точный
фрагмент Inkbrick. Выделение идёт по порядку документа, поэтому в копию попадают строки и столбцы, где есть выделенные ячейки, а не
выделенные внутри них пусты; заголовком копия остаётся, только если в выделение попала первая строка. Выделение внутри одной ячейки
копируется как обычный текст.

**Вставка из других приложений.**

| Источник                                            | Результат                                                                                                                           |
| --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| HTML `<table>` из Excel, Google Sheets, Word и веба | таблица; `colspan`/`rowspan` раскладываются по сетке (текст — в первой ячейке области), короткие строки дополняются                 |
| то же, но таблица из одной ячейки                   | текст ячейки (так вставляется одна скопированная ячейка)                                                                            |
| текст с табуляциями без HTML                        | таблица, если в нём не меньше двух строк и двух столбцов и в каждой строке поровну ячеек; ячейки в кавычках разбираются по RFC 4180 |
| `Ctrl/Cmd+Shift+V`, блок кода                       | текст как есть                                                                                                                      |

Первая строка становится заголовком, если она в `<thead>` или состоит из `<th>` (Excel и Sheets таблицы без заголовка не размечают).
Форматирование и ссылки в ячейках сохраняются, абзацы и `<br>` — строки внутри ячейки, вложенные таблицы становятся текстом ячейки.
Выравнивание читается из `align` и `text-align`; ширины столбцов из чужих таблиц не переносятся.

**Куда встаёт таблица.** Вместо пустого абзаца или перед текстом абзаца (без пустого абзаца перед ней); в середине абзаца текст делится
на «до» и «после». Если каретка в ячейке таблицы, ячейки заполняются от каретки, а недостающие строки и столбцы добавляются; любая
другая вставка в ячейку идёт текстом. Вставка — один шаг undo.

**Пределы.** Таблица больше 2000 ячеек или 50 столбцов вставляется текстом (строки с табуляциями) — молча обрезать её нельзя.
В редакторе без `tableBlocks` любая таблица вставляется так же: абзац на строку, ячейки через табуляцию. Из кода:

```ts
import { tableFragment } from '@inkbrick/engine';

editor.dispatch({
  type: 'pasteFragment',
  payload: {
    at: { blockId, offset: 0 },
    // ячейка — строка или текст с форматированием; header, align и widths необязательны
    fragment: tableFragment(
      [
        ['Name', 'Qty'],
        ['Apple', '3'],
      ],
      { align: [undefined, 'right'] },
    ),
  },
});
```

## Экспорт

`toHtml`, `toMarkdown` и `toPlainText` из `@inkbrick/document` пишут таблицу как `<table>`, таблицу GFM и текст с табуляциями.
У GFM нет таблицы без заголовка: если `header` выключен, первой строкой идёт пустой заголовок, чтобы не потерять данные.
Вертикальная черта в ячейке экранируется, перевод строки становится `<br>`. Сами форматы текста доступны и отдельно:

```ts
import { parseDelimited, serializeDelimited } from '@inkbrick/document';

serializeDelimited([
  ['a', 'b\tc'],
  ['d', 'e'],
]); // 'a\t"b\tc"\nd\te'
parseDelimited('a,"b,c"\nd,e', ','); // [['a', 'b,c'], ['d', 'e']]
```

## Отдельный редактор таблицы

Когда нужна только таблица — поле формы, данные в карточке, редактор конфигурации, — используйте `<TableEditor>`: документ
из одной закреплённой таблицы, без ручек блока, переноса блоков и slash-меню.

```tsx
import { TableEditor } from '@inkbrick/react';

<TableEditor
  rows={[
    ['Name', 'Qty'],
    ['Apple', '3'],
  ]}
  onChange={(value) => save(value.rows)}
/>;
```

Таблицу нельзя удалить, превратить в другой блок или покинуть: `Delete` и `Backspace` на выделении всего документа очищают
ячейки, `Enter` остаётся в ячейке, курсору некуда уйти. Строки, столбцы, ширины, выравнивание, `Tab`, буфер обмена, undo,
формат и меню по правому клику работают как в таблице внутри редактора.

| Prop                                   | Что делает                                                                                            |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `rows`, `header`, `align`, `widths`    | начальное содержимое; читается один раз (по умолчанию пустая таблица 3×3)                             |
| `changeDelay`                          | пауза в мс перед `onChange`: значение собирается один раз после правок, а не на каждую клавишу        |
| `editor`                               | свой редактор из `createTableEditor` — чтобы читать и менять таблицу из кода; тогда `rows` не нужен   |
| `onChange(value)`                      | после каждой правки, undo и redo: `{ rows: string[][], header, align, widths }` — простой текст ячеек |
| `readOnly`, `label`, `className`       | режим чтения, подпись для скринридера, класс контейнера                                               |
| `locale`, `locales`, `messages`        | язык и строки интерфейса, как в `EditorProvider`                                                      |
| `formatting`, `presentation`, `keymap` | как в `EditorProvider`                                                                                |

Без React:

```ts
import { createTableEditor, tableIdOf, tableValue } from '@inkbrick/engine';
import { toMarkdown } from '@inkbrick/document';

const editor = createTableEditor({ rows: [['Name', 'Qty']] });

editor.dispatch({ type: 'insertTableRow', payload: { blockId: tableIdOf(editor), index: 1 } });
tableValue(editor); // { rows, header, align, widths }
toMarkdown(editor.document); // таблица GFM
```

Закрепление — общая возможность редактора: `editor.pin(blockId)` запрещает удалить блок, превратить его в другой тип
или вынести из родителя. Команда, которая это сделала бы, откатывается целиком и ничего не меняет (`dispatch` возвращает
`undefined`); содержимое блока правится как обычно. `editor.pin(null)` снимает закрепление.

## Проверка и восстановление

`validateSnapshot` проверяет, что в таблице есть строки и во всех строках поровну ячеек. `repairSnapshot`
дополняет короткие строки пустыми ячейками, а пустой таблице добавляет строку.

## Свои составные блоки

Механизм общий, им можно пользоваться в своих схемах (`BlockSchema`):

- `isolating` — блок нельзя удалить, склеить, перенести или дублировать общими командами;
- `scaffold(props)` — начальные потомки блока, который создаёт пользователь;
- `validate(block, getBlock)` и `repair(block, tree)` — правила поддерева, которые не выразить вложенностью.
