# Таблицы

Таблица — три типа блоков: `block:table` → строки `block:table-row` → ячейки `block:table-cell`. Ячейка — обычный
текстовый блок, поэтому форматирование, выравнивание, undo и выделение работают в ней так же, как в абзаце.
В ячейке только текст: списки, картинки и объединённые ячейки не поддерживаются.

Пока готова модель и команды движка. Отрисовка в `@inkbrick/react`, управление строками и столбцами мышью и
отдельный редактор таблицы появятся следующими этапами.

## Подключение

Во встроенный набор блоков таблица не входит — редактору без таблиц её код не нужен:

```ts
import { Editor, tableBlocks } from '@inkbrick/engine';

const editor = new Editor({ blocks: tableBlocks });
```

Только схемы (например, чтобы проверить снимок на сервере): `createSchemaRegistry(tableBlockSchemas)` из
`@inkbrick/document`.

## Создание

```ts
editor.dispatch({ type: 'insertBlock', payload: { flavour: 'block:table', afterId } });
editor.dispatch({ type: 'convertBlock', payload: { blockId, flavour: 'block:table' } });
```

Обе команды создают таблицу 3×3 одним шагом undo и возвращают позицию курсора в первой ячейке. `convertBlock`
ставит после таблицы пустой абзац. Props таблицы: `header` (первая строка — заголовок, по умолчанию `true`) и
`widths` — ширины столбцов в пикселях (`null` — по содержимому).

## Строки и столбцы

Количество и порядок строк и ячеек меняют только команды таблицы; `blockId` — id таблицы, номера — с нуля.

| Команда                                  | Что делает                                                     |
| ---------------------------------------- | -------------------------------------------------------------- |
| `insertTableRow` `{ index }`             | пустая строка на месте `index`; курсор — в её первую ячейку    |
| `deleteTableRow` `{ index }`             | удаляет строку; последнюю удалить нельзя                       |
| `moveTableRow` `{ from, to }`            | переносит строку                                               |
| `insertTableColumn` `{ index }`          | пустой столбец на месте `index`; курсор — в его верхнюю ячейку |
| `deleteTableColumn` `{ index }`          | удаляет столбец; последний удалить нельзя                      |
| `moveTableColumn` `{ from, to }`         | переносит столбец                                              |
| `setTableColumnWidth` `{ index, width }` | ширина столбца в пикселях; `null` — по содержимому             |

Каждая команда — один шаг undo; ширины столбцов переезжают вместе со столбцами. `editor.can(type, payload)`
отвечает, выполнится ли команда.

```ts
import { locateTableCell, tableCellAt, tableSize } from '@inkbrick/engine';

const getBlock = (id: string) => editor.document.getBlock(id);

locateTableCell(getBlock, cellId); // { tableId, row, column }
tableSize(getBlock, tableId); // { rows, columns }
tableCellAt(getBlock, tableId, 0, 2); // id ячейки
```

## Как ведут себя обычные команды

Строка и ячейка помечены в схеме `isolating: true` — это неделимые части таблицы:

- **Enter** в ячейке вставляет перевод строки и никогда не выходит из неё.
- **Backspace** в начале ячейки ничего не делает: ячейка не становится абзацем и не склеивается с соседней.
- **Удаление выделения**, у которого хотя бы одна граница в ячейке, очищает текст ячеек, а сетку не трогает.
  Обычные блоки, попавшие в выделение целиком, удаляются. Выделение, которое покрывает таблицу целиком
  (от абзаца до неё до абзаца после), удаляет её, как любой другой блок.
- **Вставка из буфера** в ячейку идёт текстом: блоки фрагмента становятся строками.
- `insertBlock`, `delete-block`, `moveBlock`, `duplicateBlock`, `convertBlock` для строк и ячеек не выполняются.
  Саму таблицу можно удалять, переносить и дублировать как обычный блок.

## Проверка и восстановление

`validateSnapshot` проверяет, что в таблице есть строки и во всех строках поровну ячеек. `repairSnapshot`
дополняет короткие строки пустыми ячейками, а пустой таблице добавляет строку.

## Свои составные блоки

Механизм общий, им можно пользоваться в своих схемах (`BlockSchema`):

- `isolating` — блок нельзя удалить, склеить, перенести или дублировать общими командами;
- `scaffold(props)` — начальные потомки блока, который создаёт пользователь;
- `validate(block, getBlock)` и `repair(block, tree)` — правила поддерева, которые не выразить вложенностью.
