# Фон блока

У текстовых блоков (абзац, заголовок, цитата, пункт списка, callout, toggle) есть свойство `background` — цвет фона всего блока.
В меню блока (ручка слева, «Фон») сетка из двух рядов по восемь образцов: «Без фона», 14 оттенков и «Свой цвет…». Выбор — один шаг отмены.

```ts
editor.dispatch({ type: 'setBlockProps', payload: { blockId, props: { background: 'yellow' } } });
editor.dispatch({ type: 'setBlockProps', payload: { blockId, props: { background: undefined } } }); // снять
```

- **Цвета** — `BLOCK_BACKGROUNDS`: `gray`, `brown`, `orange`, `yellow`, `lime`, `green`, `teal`, `cyan`, `blue`, `indigo`, `purple`,
  `magenta`, `pink`, `red` (новые: `lime`, `teal`, `cyan`, `indigo`, `magenta`). В документе хранится имя цвета, оттенок выбирает тема:
  фон разбавлен (35% оттенка подсветки), поэтому текст читаем и в светлой, и в тёмной теме. Чёрный и белый не входят.
- **Свой цвет.** «Свой цвет…» раскрывает под палитрой выбор цвета с прозрачностью (`@inkbrick/dom/color-picker`: квадрат
  насыщенности и яркости, ползунки оттенка и прозрачности, поля HEX / RGB / HSB и процент прозрачности). Выбор начинается с 35 %
  прозрачности, как у оттенков палитры; «Применить» или Enter записывают цвет одной правкой как `#rrggbbaa`
  (`background: '#12ab3459'`), «Отмена» и Escape закрывают выбор, не трогая меню. Документы со старым `#rrggbb` читаются как раньше. Выбран путь «расширить схему», а не «подобрать ближайшее имя»: так выбранный цвет не меняется и не
  теряется при копировании. Схема всех шести блоков принимает имя из палитры **или** ровно `#rrggbb` / `#rrggbbaa` (`blockBackgroundSchema`);
  `#fff`, `rgb(…)`, `url(…)`, имена вне палитры и значения с `;` отклоняет и движок (`can('setBlockProps', …)` возвращает `false`), и
  `repairSnapshot` (повреждённое значение заменяется props по умолчанию, как и раньше). В `style` блока попадает только прошедший схему
  hex, в переменную `--inkbrick-block-background`: `#rrggbbaa` рисуется ровно таким, как выбран (`data-background="custom-alpha"`),
  а старый `#rrggbb` разбавляется теми же 35%, что и оттенок палитры (`data-background="custom"`). Читать любой допустимый фон
  можно через `getBlockBackgroundColor(block)`, а `getBlockBackground(block)` по-прежнему возвращает только имена палитры.
- **С цветом текста и подсветкой.** Это три независимых слоя: цвет текста (`color`) и подсветка слов (`backgroundColor`) работают поверх
  фона блока. Подсветка слов остаётся заметной на любом оттенке; если нужен другой контраст, меняйте цвет текста.
- **Превращение.** При превращении блока в другой текстовый тип (абзац → заголовок, список → цитата) фон остаётся; у типа без фона (код,
  формула) он пропадает. Enter в цитате и списке переносит фон на новый блок, как и остальные свойства; абзац после заголовка
  создаётся без фона.
- **Вид.** Атрибут `data-background` у блока (`custom` для своего цвета) и правило `[data-background='…']` в `@inkbrick/styles`; поля вынесены наружу
  (`margin-inline: -8px` с `padding-inline: 8px`), поэтому текст стоит там же, где у блоков без фона. Переопределяется стилями
  приложения (слой `@layer`, `:where()`).
- **Экспорт.** `toHtml` пишет `style="background-color:…"` (оттенок светлой темы, у блока с выравниванием оба свойства в одном
  `style`); свой цвет `#rrggbbaa` выводится как есть, старый `#rrggbb` — как `#rrggbb59` (прозрачность 35%, как в редакторе). Markdown и простой текст фон не передают. Вставка из HTML фон блока не читает: подсветка слов (`background-color` у `span`)
  по-прежнему переносится как раньше.
- **Свои блоки и меню.** Строку цветов показывает меню блока, если движок принимает `background` у этого блока
  (`editor.can('setBlockProps', …)`): достаточно добавить `background: blockBackgroundSchema.optional()` (имена палитры, `#rrggbb` и `#rrggbbaa`; только имена — `z.enum(BLOCK_BACKGROUNDS).optional()`) в
  схему своего блока и `{...backgroundAttrs(block)}` (или `data-background={getBlockBackground(block)}` для имён) в его разметку. Свой `slots.BlockMenu` получает ряд в `props.background`
  (`current`, `options`, `onPick`) и может его не показывать.
- Таблицы, колонки, изображения, код и формулы без фона (у ячеек таблицы цвет задают через подсветку текста).
