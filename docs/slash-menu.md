# Slash-меню и типы блоков

## Встроенные блоки

| flavour           | Что это                                                | Props             | Enter                                          |
| ----------------- | ------------------------------------------------------ | ----------------- | ---------------------------------------------- |
| `block:paragraph` | Текст                                                  | `alignment`       | делит блок                                     |
| `block:heading`   | Заголовок 1–6                                          | `level`, `align`  | следующая строка — параграф                    |
| `block:list`      | Пункт списка (bullet / ordered / todo)                 | `type`, `checked` | делит; Enter в пустом пункте — выход           |
| `block:quote`     | Цитата                                                 | —                 | делит; Enter в пустой цитате — выход           |
| `block:code`      | Код (моноширинный, без подсветки)                      | `language`        | перевод строки; Enter на пустой строке — выход |
| `block:divider`   | Горизонтальная линия (без текста)                      | —                 | —                                              |
| `block:formula`   | Формула LaTeX отдельной строкой (`/formula` или `$$ `) | `latex`           | —                                              |

В блоке кода `Tab` вставляет отступ из двух пробелов, а форматирование текста (жирный и т. п.) не применяется.

### Tab, вложенность и выход из списков

- `Tab` / `Shift+Tab` **никогда не уводят фокус** из редактора. Вкладывать и поднимать можно только блоки,
  которые схема помечает как `indentable: true` (пункты списка). Параграф Tab-ом никуда не «проваливается».
- `Shift+Tab` сохраняет порядок чтения: блоки, шедшие после поднятого, становятся его потомками.
- `Enter` в пустом блоке (`exitWhenEmpty`): вложенный блок поднимается на уровень выше, блок верхнего уровня
  становится параграфом — пустые параграфы не копятся внутри списка.
- `Backspace` в начале блока работает ступенчато: вложенный блок **поднимается** → не-параграф
  **становится параграфом** → параграф **склеивается** с предыдущим (если перед ним разделитель — удаляется он).

### Markdown-шорткаты

В начале параграфа, затем пробел: `# `…`###### ` (заголовок), `- ` / `* ` (список), `1. ` (нумерованный),
`[] ` (todo), `> ` (цитата), ` ``` ` (код), `--- ` (разделитель). Шорткат отменяется одним `Ctrl/Cmd+Z`.

### Поведение Enter задаётся схемой

```ts
const MySchema: BlockSchema = {
  // …
  enter: {
    mode: 'split', // 'newline' — вставлять перевод строки (как в коде)
    nextFlavour: 'block:paragraph', // тип блока, создаваемого после Enter
    exitWhenEmpty: true, // Enter в пустом блоке превращает его в параграф
  },
};
```

## Slash-меню

Набор `/` в начале блока или после пробела открывает меню; дальнейший ввод фильтрует пункты.

| Клавиша                 | Действие                                               |
| ----------------------- | ------------------------------------------------------ |
| `↑` / `↓`               | выбрать пункт (по кругу)                               |
| `Enter` / `Tab`         | применить пункт (если пунктов нет — обычный Enter/Tab) |
| `Esc`                   | закрыть, текст остаётся                                |
| `←` / клик / `⌫` за `/` | закрыть                                                |

Применение пункта удаляет `/запрос` и превращает блок (команда `convertBlock`) — **одним шагом undo**.
Меню не открывается внутри блока кода. Пробел после запроса без совпадений закрывает меню.
Для типов без текста (разделитель) пустой блок заменяется им, непустой остаётся, а следом создаётся параграф.

### Свои пункты и свой вид меню

```tsx
const items: SlashMenuItem[] = [
  {
    id: 'callout',
    title: 'Callout',
    description: 'Highlighted note',
    keywords: ['info'],
    icon: '💡',
    flavour: 'block:callout',
  },
];

<EditorProvider
  editor={editor}
  slashItems={items} // дополняет стандартные; одинаковый id заменяет стандартный пункт; false — выключить меню
  slots={{ SlashMenu: MyMenu }} // свой компонент меню
/>;
```

`MyMenu` получает `{ items, query, activeIndex, position, onSelect, onHover, onClose }` и только рисует:
клавиатуру, фильтрацию и применение выбора ведёт редактор. Корневой элемент меню должен гасить `mousedown`
(`onMouseDown={e => e.preventDefault()}`), иначе клик уведёт фокус из редактора.
Пункт показывается, только если его `flavour` зарегистрирован в схеме и допустим внутри родителя блока.

## Свой тип блока

1. Схема (`BlockSchema`) с `propsSchema`, правилами вложенности и при необходимости `enter` → `new Editor({ blocks: [MySchema] })`.
2. Компонент → `components={{ 'block:my': MyView }}` (текст — через `<Editable>`).
3. Пункт меню → `slashItems`.

Блоки без текста помечайте в схеме `inline: false`: для них не создаётся текстовая область, а команды ввода их игнорируют.
