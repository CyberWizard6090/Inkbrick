# Цвет текста, подсветка и выравнивание

## Цвет текста и подсветка

В toolbar над выделением две кнопки: **цвет текста** (A) и **подсветка** (маркер). Панель — сетка из трёх рядов по шесть
образцов: сброс, 16 цветов палитры и «Свой цвет…». Это независимые атрибуты: `color` (текст) и `backgroundColor` (фон).

```ts
{ insert: 'важно', attributes: { color: 'red', backgroundColor: 'yellow' } }
```

- В документе хранится **имя цвета** палитры (`COLOR_NAMES`): `black`, `white`, `gray`, `brown`, `orange`, `yellow`, `lime`, `green`,
  `teal`, `cyan`, `blue`, `indigo`, `purple`, `magenta`, `pink`, `red`. Оттенок выбирает тема: в светлой и тёмной теме один и тот же
  `red` читаем, а документ не зависит от темы. Имена `lime` (салатовый), `teal` (бирюзовый), `cyan` (голубой), `indigo` (индиго) и
  `magenta` (маджента) добавлены позже остальных; старые документы читаются как раньше, имена остальных цветов не менялись, а
  порядок образцов в панели только следует кругу оттенков. Подписи образцов (`aria-label` и подсказка) есть на русском и английском.
- **Свой цвет.** Последний образец панели, «Свой цвет…», раскрывает под палитрой выбор цвета с прозрачностью
  (`@inkbrick/color-picker`: квадрат насыщенности и яркости, ползунки оттенка и прозрачности, поля HEX / RGB / HSB и процент
  прозрачности; мышь, палец и клавиатура — стрелки, с Shift шаг крупнее). Цвет текста сохраняется как `#rrggbb`, а с прозрачностью
  меньше 100 % — `#rrggbbaa` (`color: '#12ab3480'`); подсветка — всегда `#rrggbbaa`, выбор для неё начинается с 35 %, как у оттенков
  палитры, и рисуется ровно таким, как выбран (старая подсветка `#rrggbb` по-прежнему разбавляется до 35 %). Значение проходит ту же
  проверку, что и любой CSS-цвет (`safeCssColor`). Образец — обычная кнопка: Enter или пробел раскрывают выбор, «Применить» или Enter в
  поле применяют цвет одним шагом undo, «Отмена» и Escape закрывают выбор и возвращают фокус на образец. У выбранного своего цвета образец и индикатор кнопки в toolbar показывают его. От темы такой цвет не зависит, поэтому за
  контраст отвечает тот, кто его выбрал.
- **Контраст.** У каждого из пяти новых цветов текст на белой странице (светлая тема) и на `#292929` (тёмная), а также текст по
  умолчанию поверх подсветки и поверх фона блока имеют контраст не ниже 4,5:1 (WCAG AA); это проверяет `tests/E2E/a11y.spec.ts`.
- Разметка: `<span data-inkbrick-color="red" data-inkbrick-bg="yellow">`. Оттенки — токены `--inkbrick-color-<имя>` (текст) и
  `--inkbrick-highlight-<имя>` (фон) в `@inkbrick/styles`; переопределяются обычным CSS: `:root { --inkbrick-highlight-yellow: #ffe066 }`.
- Допустимы и произвольные безопасные CSS-цвета (`#ff0000`, `rgb(…)`, `hsl(…)`, имя): они рисуются inline-стилем и от темы
  не зависят. Всё прочее (`url(…)`, `var(…)`, `;`) отклоняется командой и игнорируется при отрисовке и вставке.
- Текст, набранный сразу после цветного, наследует цвет (как в текстовых редакторах).
- Применяется к выделению из нескольких блоков одним шагом undo; в блоках кода не работает.
- Программно: `editor.dispatch({ type: 'setInlineAttributes', payload: { from, to, attributes: { color: 'red' } } })`;
  `undefined` снимает цвет. Текущий цвет выделения — `editor.formatsAt(from, to).color` / `.backgroundColor`
  (есть, только если он одинаков у всего выделенного текста).

Копирование и вставка внутри редактора переносят цвет как есть (имя или `#rrggbb`). В буфер для других приложений цвет уходит
как hex светлой темы; при вставке из HTML принимаются только безопасные значения.

## Выравнивание

Четыре режима: слева, по центру, справа, по ширине. Кнопки в toolbar и сочетания клавиш (работают и без выделения —
выравнивается блок с кареткой):

| Действие   | Сочетание          |
| ---------- | ------------------ |
| По левому  | `Ctrl/Cmd+Shift+L` |
| По центру  | `Ctrl/Cmd+Shift+E` |
| По правому | `Ctrl/Cmd+Shift+R` |
| По ширине  | `Ctrl/Cmd+Shift+J` |

- Поддерживают выравнивание абзац, заголовок, цитата, пункт списка и заметка. Блоки кода, картинки и формулы
  пропускаются; выравнивание нескольких блоков — один шаг undo.
- Хранится в props блока: у абзаца `alignment`, у остальных `align` (значения `left|center|right|justify`). Скрывает
  различие `getBlockAlign(block)` / `alignProps(flavour, align)` из `@inkbrick/document`.
- Разметка: `data-align` на блоке (`[data-inkbrick-block][data-align='center']`). Вложенный пункт списка выравнивается независимо
  от родителя.
- Команда: `editor.dispatch({ type: 'setAlign', payload: { from, to, align: 'center' } })`.

## Экспорт

HTML получает `style="color:…;background-color:…"` (имена палитры, в том числе новые, превращаются в оттенки светлой темы
`COLOR_HEX`, свои цвета выводятся как есть) и
`style="text-align:…"` у выровненных блоков. Markdown и простой текст цвета и выравнивания не передают.
