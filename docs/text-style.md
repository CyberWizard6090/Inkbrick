# Цвет текста, подсветка и выравнивание

## Цвет текста и подсветка

В toolbar над выделением две кнопки: **цвет текста** (A) и **подсветка** (маркер). Панель показывает палитру из девяти
цветов и сброс. Это независимые атрибуты: `color` (текст) и `backgroundColor` (фон).

```ts
{ insert: 'важно', attributes: { color: 'red', backgroundColor: 'yellow' } }
```

- В документе хранится **имя цвета** палитры: `black`, `white`, `gray`, `brown`, `orange`, `yellow`, `green`, `blue`, `purple`, `pink`,
  `red` (`COLOR_NAMES`). Оттенок выбирает тема: в светлой и тёмной теме один и тот же `red` читаем, а документ не
  зависит от темы.
- Разметка: `<span data-inkbrick-color="red" data-inkbrick-bg="yellow">`. Оттенки — токены `--inkbrick-color-<имя>` (текст) и
  `--inkbrick-highlight-<имя>` (фон) в `@inkbrick/styles`; переопределяются обычным CSS: `:root { --inkbrick-highlight-yellow: #ffe066 }`.
- Допустимы и произвольные безопасные CSS-цвета (`#ff0000`, `rgb(…)`, `hsl(…)`, имя): они рисуются inline-стилем и от темы
  не зависят. Всё прочее (`url(…)`, `var(…)`, `;`) отклоняется командой и игнорируется при отрисовке и вставке.
- Текст, набранный сразу после цветного, наследует цвет (как в текстовых редакторах).
- Применяется к выделению из нескольких блоков одним шагом undo; в блоках кода не работает.
- Программно: `editor.dispatch({ type: 'setInlineAttributes', payload: { from, to, attributes: { color: 'red' } } })`;
  `undefined` снимает цвет. Текущий цвет выделения — `editor.formatsAt(from, to).color` / `.backgroundColor`
  (есть, только если он одинаков у всего выделенного текста).

## Выравнивание

Четыре режима: слева, по центру, справа, по ширине. Кнопки в toolbar и сочетания клавиш (работают и без выделения —
выравнивается блок с кареткой):

| Действие   | Сочетание          |
| ---------- | ------------------ |
| По левому  | `Ctrl/Cmd+Shift+L` |
| По центру  | `Ctrl/Cmd+Shift+E` |
| По правому | `Ctrl/Cmd+Shift+R` |
| По ширине  | `Ctrl/Cmd+Shift+J` |

- Поддерживают выравнивание абзац, заголовок, цитата, пункт списка и заметка. Блоки кода, картинки и формулы
  пропускаются; выравнивание нескольких блоков — один шаг undo.
- Хранится в props блока: у абзаца `alignment`, у остальных `align` (значения `left|center|right|justify`). Скрывает
  различие `getBlockAlign(block)` / `alignProps(flavour, align)` из `@inkbrick/document`.
- Разметка: `data-align` на блоке (`[data-inkbrick-block][data-align='center']`). Вложенный пункт списка выравнивается независимо
  от родителя.
- Команда: `editor.dispatch({ type: 'setAlign', payload: { from, to, align: 'center' } })`.

## Экспорт

HTML получает `style="color:…;background-color:…"` (имена палитры превращаются в оттенки светлой темы) и
`style="text-align:…"` у выровненных блоков. Markdown и простой текст цвета и выравнивания не передают.
