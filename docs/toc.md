# Оглавление

Блок `block:toc` показывает заголовки документа ссылками. В документе хранится только настройка `maxLevel`, сам список
собирается из заголовков при отрисовке и экспорте, поэтому всегда актуален: заголовок добавили, переименовали, сменили
уровень или удалили — оглавление обновилось.

## Подключение

Во встроенный набор блоков оглавление не входит — редактору без него его код не нужен. Один и тот же список
передаётся и редактору, и провайдеру:

```tsx
import { Editor } from '@inkbrick/engine';
import { EditorProvider, DocumentView, tocBlocks } from '@inkbrick/react';

const editor = new Editor({ blocks: tocBlocks });

<EditorProvider editor={editor} blocks={tocBlocks}>
  <DocumentView />
</EditorProvider>;
```

Вместе с таблицами: `blocks: [...tableBlocks, ...tocBlocks]`. Без React — только схемы и команды: `tocBlocks` из
`@inkbrick/engine`; только схема (проверить снимок на сервере) — `createSchemaRegistry(tocBlockSchemas)` из
`@inkbrick/document`.

## В редакторе

- В slash-меню появляется пункт «Оглавление» (`/toc`, `/оглавление`, `/contents`).
- Заголовки идут в порядке документа; вложенность — по уровню: `h2` после `h1` вкладывается в него, пропущенные
  уровни пустых ступеней не оставляют.
- Нажатие на пункт ставит курсор в начало заголовка и прокручивает к нему.
- Маленькая кнопка справа сверху (появляется при наведении) переключает глубину: `H1`, `H1–H2`, … `H1–H6`.
- Пока заголовков нет, показывается подсказка. В режиме только чтения кнопки глубины нет, ссылки работают.

```ts
editor.dispatch({ type: 'insertBlock', payload: { flavour: 'block:toc', afterId } });
editor.dispatch({ type: 'setBlockProps', payload: { blockId: tocId, props: { maxLevel: 2 } } });
```

## Экспорт

`toHtml`, `toMarkdown` и `toPlainText` пишут оглавление вложенным списком заголовков до `maxLevel`: `<nav><ul>…`, список
`- …` с отступами и текст. Ссылок на заголовки в экспорте нет — у них нет постоянных адресов. Без заголовков оглавление
в экспорт не попадает.

## Разметка и стили

`<nav data-inkbrick-block="toc">` с `<ul>`; ссылка — `<button data-inkbrick-part="link">`, подсказка —
`data-inkbrick-part="empty"`, кнопка глубины — `data-inkbrick-part="levels"`. Своя отрисовка — через `components`:
`{ 'block:toc': MyToc }`; список заголовков можно получить хуком `useHeadings(maxLevel)`.

## Панель сбоку

Оглавление можно держать не блоком в тексте, а панелью у края окна: список заголовков, подсветка текущего раздела при прокрутке,
нажатие переносит курсор в заголовок. Панель входит в `@inkbrick/react` и кладётся в провайдер рядом с документом:

```tsx
import { EditorProvider, DocumentView, TocPanel } from '@inkbrick/react';

<EditorProvider editor={editor}>
  <DocumentView />
  <TocPanel side="right" maxLevel={3} />
</EditorProvider>;
```

| Свойство    | Что делает                                       | По умолчанию       |
| ----------- | ------------------------------------------------ | ------------------ |
| `side`      | `'left'` или `'right'`: у какого края окна стоит | `'right'`          |
| `maxLevel`  | самый глубокий уровень заголовков в панели (1–6) | `6`                |
| `label`     | подпись для чтения с экрана                      | «На этой странице» |
| `className` | свой класс                                       | —                  |

- Панель не показывается по умолчанию: она появляется только там, где вы её поставили. Без заголовков она пустая и не выводится.
- Висит у края окна (`position: fixed`) и скрыта, когда окно уже 1100 px: места рядом с текстом нет.
- Текущий раздел — последний заголовок, поднявшийся выше линии в 120 px от верха окна. В виртуальном рендерере заголовки вне
  окна в DOM не стоят: текущим считается тот, что идёт перед первым отрисованным заголовком ниже линии.
- Части для стилей: `data-inkbrick-ui="toc-panel"` (`data-side`), `data-inkbrick-part="link"`, у пункта `data-active`.
  Блок `block:toc` остаётся: панель и блок работают независимо.
