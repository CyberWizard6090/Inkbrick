# Копирование и вставка

## Что попадает в буфер при копировании

Копирование (и вырезание) выделения — в том числе из нескольких блоков — кладёт в буфер **три формата**:

| Формат                            | Для чего                                                                                                                                                                                     |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `text/plain`                      | простой текст: блок — строка, вложенные блоки с отступом                                                                                                                                     |
| `text/html`                       | чистый семантический HTML (`<h1>`, `<ul>`, `<strong>`, `<a>`, `<pre><code>`, `<hr>`…) для Word, Google Docs, почты; без служебных атрибутов редактора                                        |
| `application/x-inkbrick-fragment` | точный фрагмент Inkbrick: типы блоков, props, форматирование, вложенность. Дублируется в атрибуте `data-inkbrick-fragment` HTML — на случай приложений, которые вырезают собственные форматы |

Копирование работает и в режиме только чтения; `Ctrl/Cmd+A` в нём выделяет только документ.

## Что и как вставляется

Выбирается лучший из доступных форматов: **точный фрагмент → HTML → простой текст**.

- Один текстовый блок встраивается в текущий как текст (форматирование сохраняется).
- Несколько блоков: текущий блок делится по каретке — «голова» + первый блок, средние блоки, последний блок + «хвост».
- **Пустой** блок перенимает тип _целиком_ скопированного блока (вставили заголовок — получили заголовок);
  часть слова из заголовка тип не меняет.
- Выделение заменяется вставкой; вставка — **один шаг undo**.
- Типы, которых нет в схеме редактора, и типы, которые нельзя положить в этот контейнер, превращаются в параграфы:
  содержимое не теряется. Недопустимые props заменяются значениями по умолчанию.
- Блоки, лежащие внутри пункта списка и не подходящие по типу, остаются на его уровне (как параграфы).
- В **блок кода** вставляется только простой текст.
- Адрес (`https://…`, `mailto:…`) поверх выделенного текста делает его ссылкой, а не заменяет.
- `Ctrl/Cmd+Shift+V` — вставить только текст.
- Картинка в буфере (снимок экрана, «копировать изображение») и перетаскиваемые файлы-изображения вставляются как блок
  «Изображение» (см. [изображения](images-and-callout.md)); если рядом в буфере есть текст — это обычная вставка.

### Разбор HTML из других приложений

Понимает `<img>`/`<figure>` (только абсолютные http(s)- и data:-адреса) и `<aside data-callout>`; Google Docs (обёртка `<b style="font-weight:normal">`, жирный/курсив/подчёркивание через `style`,
вложенные `<ul><ul>`), Word (абзацы-списки `mso-list` с уровнями и нумерацией, `<o:p>`), заголовки, цитаты,
`<pre><code class="language-…">`, `<hr>`, чекбоксы (`to-do`) и таблицы (каждая строка — абзац, ячейки через табуляцию).
Пробелы сворачиваются как в браузере, пустые абзацы отбрасываются.

### Безопасность

Содержимое буфера — **недоверенный ввод**:

- HTML разбирается в изолированном документе (`DOMParser`), в страницу **никогда не вставляется как разметка** —
  скрипты, обработчики `on*`, картинки, iframe, формы и стили не влияют ни на что; из HTML читается только структура и текст;
- ссылки проходят `normalizeLinkUrl`/`isSafeUrl` (`javascript:`, `data:` и т. п. отбрасываются), а `example.com` дополняется до `https://example.com`;
- JSON фрагмента проверяется (`sanitizeFragment`): ограничены глубина (12), число блоков (5000) и размер текста,
  оставлены только известные атрибуты (`bold`, `italic`, `underline`, `strike`, `code`, безопасный `link`, цвета);
- слишком большой или испорченный HTML/JSON игнорируется, и вставка продолжается следующим форматом.

## API

```ts
// движок
const fragment = editor.copyFragment(from, to); // Fragment: { blocks: FragmentBlock[] }
editor.dispatch({ type: 'pasteFragment', payload: { at: { blockId, offset }, fragment } }); // → { blockId, offset } каретки
fragmentToHtml(fragment);
fragmentToPlainText(fragment);
sanitizeFragment(untrusted);

// React
htmlToFragment(html); // Fragment | null
```

Вставку можно вызвать и из кода; в режиме чтения команда отклоняется, как и любая другая.

## Ограничения

- Файлы, не являющиеся поддерживаемыми изображениями, игнорируются.
- Таблицы вставляются как абзацы с табуляцией.
- Блоки внутри вложенного пункта списка, не подходящие по типу, превращаются в параграфы, а не поднимаются на верхний уровень.
