# Выделение через несколько блоков

Браузер не позволяет выделению выходить за пределы одного `contenteditable`-элемента. Поэтому
редактируемым элементом является не каждый блок, а **корень `<DocumentView>`**; блоки (`<Editable>`)
лежат внутри него и сами не редактируются. Выделение — обычное браузерное: мышь, `Shift+стрелки`,
`Ctrl/Cmd+A` (выделяет весь документ).

Ввод по-прежнему не меняет DOM напрямую: корень перехватывает `beforeinput`, превращает выделение в
координаты документа (`blockId` + смещение в тексте) и вызывает команды движка.

## Что работает над выделением из нескольких блоков

| Действие                               | Команда движка                                                    |
| -------------------------------------- | ----------------------------------------------------------------- |
| Backspace / Delete / вырезание         | `deleteRange`                                                     |
| Ввод текста поверх выделения           | `deleteRange` + `replaceText` (один шаг undo)                     |
| Enter                                  | `deleteRange` + `splitBlock` (один шаг undo)                      |
| Вставка (в том числе многострочная)    | `deleteRange` + `replaceText`/`splitBlock`                        |
| Жирный / курсив / подчёркивание и т.д. | `toggleFormatRange` (снимает, если весь текст уже отформатирован) |

Правила `deleteRange`:

- Первый блок сохраняет свой тип и получает «хвост» последнего блока; блоки между ними удаляются.
- Дочерние блоки последнего блока переходят к первому (или встают после него, если схема не допускает вложенность).
- Контейнеры (`page`, `note`; в схеме `inline: false`) не могут быть границами выделения.
- Если внутри диапазона есть блок **неизвестного типа**, команда не выполняется — данные, смысл которых
  редактору неизвестен, не удаляются.
- Курсор после удаления ставится в точку склейки.

## Для разработчиков

- Свой блок с текстом — это компонент с `<Editable>`; он автоматически участвует в выделении.
- Блок-контейнер без текста помечайте в схеме `inline: false`.
- Нередактируемый виджет внутри блока (кнопка, маркер, картинка) помечайте `contentEditable={false}`.
- Команды можно вызвать и из кода: `editor.dispatch({ type: 'deleteRange', payload: { from, to } })`,
  `{ blockId, offset }` в любом порядке.

## Ограничения

- Копирование использует браузерное: в буфер попадает текст выделения; форматирование внутри редактора
  при вставке не переносится (вставляется простой текст).
- Перетаскивание выделенного текста (drag&drop) отключено.
