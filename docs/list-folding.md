# Сворачивание пунктов списка

У пункта списка с вложенными блоками появляется стрелка: нажатие прячет вложенные блоки, повторное показывает их. То же делает
`Ctrl/Cmd+Enter`, когда каретка стоит в пункте. Состояние лежит в документе (`collapsed` в props пункта), сохраняется вместе с
ним и входит в историю правок. Работает у маркированных, нумерованных списков и списков задач. Для заголовков есть своё
[сворачивание](heading-folding.md).

## Подключение

Не входит в набор по умолчанию. Одна строка в провайдере:

```tsx
import { EditorProvider, DocumentView, listFolding } from '@inkbrick/react';

<EditorProvider editor={editor} {...listFolding}>
  <DocumentView />
</EditorProvider>;
```

`listFolding` — это `components` (пункт со стрелкой) и `keymap` (клавиши). Заголовки и пункты сразу: `{...folding}`. Если у провайдера
уже есть свои `components` или `keymap`, объедините вручную: `components={{ ...listFolding.components, ...mine }}`,
`keymap={[...listFolding.keymap, ...mine]}`.

## Поведение

- Стрелка стоит в конце строки пункта (слева полосу занимает ручка блока) и есть только у пункта с вложенными блоками.
- Скрытые блоки не рисуются (их нет в DOM), в модели они остаются: копирование, экспорт, поиск, счётчик слов и undo видят их как
  раньше. Экспорт в HTML и Markdown сворачивание не учитывает.
- Каретка, которая была во вложенном блоке, при сворачивании переходит на сам пункт.
- `Tab`, который вложил бы блок в свёрнутый пункт, сначала разворачивает его: иначе блок исчез бы с экрана.
- Enter в конце пункта создаёт соседний пункт, который начинается развёрнутым (`collapsed` остаётся у части, где вложенные).
- Удаление свёрнутого пункта удаляет и его вложенные блоки, как и у развёрнутого.
- В режиме только чтения читатель сворачивает пункт для себя: документ при этом не меняется.
- Виртуальный рендерер (`renderer="virtual"`): вложенные блоки свёрнутого пункта в оценку высоты не входят, как и у закрытого
  переключателя.
- Части для стилей: стрелка — `data-inkbrick-part="fold"` внутри строки пункта (`data-inkbrick-part="row"`), у пункта
  `data-foldable` и `data-collapsed`.
