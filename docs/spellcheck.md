# Проверка орфографии

Редактор использует проверку браузера: красное подчёркивание и исправления в контекстном меню браузера. Свои словари не нужны,
словари и список языков даёт браузер. По умолчанию проверка **выключена**; включается в провайдере:

```tsx
<EditorProvider editor={editor} locale="ru" spellcheck>
  <DocumentView />
</EditorProvider>

// язык текста не совпадает с языком интерфейса
<EditorProvider editor={editor} locale="en" spellcheck={{ lang: 'de' }}>…</EditorProvider>
```

- **Язык.** Корень документа получает `lang`: по умолчанию язык интерфейса (`locale`), либо `spellcheck.lang`. По нему браузер выбирает
  словарь (в Chrome и Firefox это работает, Safari подбирает язык сам и `lang` может не учитывать).
- **Что не проверяется.** Блоки кода, формулы (поле LaTeX и встроенные формулы), слова с форматом «код» и ссылки. Остальной текст, подписи
  к изображениям и коду проверяются.
- **Только правка.** В режиме чтения проверка выключена (`spellcheck="false"`): подчёркивать нечего.
- **Теги** `#tag` подчёркиваются как обычные слова: они раскрашиваются через CSS Highlight API, и исключить часть текстового узла из
  проверки нельзя.
- **Песочница:** включена; `?spellcheck=off` выключает при загрузке, переключатель — в «Настройки».
- Не входит: язык отдельного блока или фрагмента (весь документ в одном языке) и собственное подчёркивание.
  Подчёркивание рисует браузер, поэтому на него не влияют стили редактора, а E2E в Chromium без словарей его не видит: тесты
  проверяют атрибуты разметки.

## Варианты исправления в контекстном меню

Своё контекстное меню редактора заменяет меню браузера, а браузер не отдаёт страницам ни варианты исправления, ни даже то, что
слово подчёркнуто. Поэтому варианты берутся из источника, который подключает приложение, — `spellcheck.checker`:

```tsx
import { createSpellchecker } from '@inkbrick/spellcheck';
import SpellWorker from '@inkbrick/spellcheck/worker?worker'; // Vite; другой сборщик — свой способ запустить Worker

const spellchecker = createSpellchecker({
  worker: () => new SpellWorker(),
  languages: {
    ru: () => loadDictionary('/dictionaries/ru'), // { aff, dic } — текст или байты файлов Hunspell
    en: () => loadDictionary('/dictionaries/en'),
  },
  personal: savedWords, // личный словарь
  onAdd: (word) => saveWord(word),
});

<EditorProvider editor={editor} spellcheck={{ checker: spellchecker }}>
  …
</EditorProvider>;
```

- **Меню.** Правый клик по слову без выделения: над «Вырезать» — до пяти вариантов (полужирным) и «Добавить в словарь»; пока словарь
  грузится — «Проверка орфографии…», если вариантов нет — «Нет вариантов». Выбор заменяет слово одним шагом отмены. У верного слова
  меню обычное. Слова в коде, ссылках и формулах не проверяются.
- **`@inkbrick/spellcheck`** — проверка по словарям Hunspell (`nspell`). Язык слова — по алфавиту (кириллица → `ru`, латиница → `en`,
  `languageOf` меняет правило); словарь языка грузится при первом его слове. Русский словарь разбирается около двух секунд и занимает
  около 200 МБ, поэтому разбор и поиск — в Web Worker (`worker`); без него — в основном потоке. Варианты упорядочены: меньше правок,
  та же длина и первая буква. Пакет работает и без редактора.
- **Словари** приложение подключает само, со своей лицензией и весом: например, `dictionary-ru` (BSD) и `dictionary-en` (MIT/BSD).
  Их пакеты экспортируют только вход для Node, поэтому в браузер нужны сами файлы `index.aff` и `index.dic` (в Vite —
  `import aff from '…/dictionary-ru/index.aff?url'`).
- **Свой источник.** Подойдёт любой объект `{ suggest(word): Promise<string[] | null>; add?(word) }` (тип `Spellchecker` из
  `@inkbrick/react`): например, сервер с проверкой.
- **Песочница** подключает русский и английский словари; добавленные слова хранятся в `localStorage`.
