# Проверка орфографии

Редактор использует проверку браузера: красное подчёркивание и исправления в контекстном меню браузера. Свои словари не нужны,
словари и список языков даёт браузер. По умолчанию проверка **выключена**; включается в провайдере:

```tsx
<EditorProvider editor={editor} locale="ru" spellcheck>
  <DocumentView />
</EditorProvider>

// язык текста не совпадает с языком интерфейса
<EditorProvider editor={editor} locale="en" spellcheck={{ lang: 'de' }}>…</EditorProvider>
```

- **Язык.** Корень документа получает `lang`: по умолчанию язык интерфейса (`locale`), либо `spellcheck.lang`. По нему браузер выбирает
  словарь (в Chrome и Firefox это работает, Safari подбирает язык сам и `lang` может не учитывать).
- **Что не проверяется.** Блоки кода, формулы (поле LaTeX и встроенные формулы), слова с форматом «код» и ссылки, ячейки таблицы
  с типами столбца `url`, `email`, `phone`, числа и метки выбора (`spellcheck="false"` у них в разметке). Остальной текст, подписи
  к изображениям и коду проверяются.
- **Только правка.** В режиме чтения проверка выключена (`spellcheck="false"`): подчёркивать нечего.
- **Теги** `#tag` подчёркиваются как обычные слова: они раскрашиваются через CSS Highlight API, и исключить часть текстового узла из
  проверки нельзя.
- **Песочница:** включена; `?spellcheck=off` выключает при загрузке, переключатель — в «Настройки».
- Не входит: язык отдельного блока или фрагмента (весь документ в одном языке), собственный словарь и собственное подчёркивание.
  Подчёркивание рисует браузер, поэтому на него не влияют стили редактора, а E2E в Chromium без словарей его не видит: тесты
  проверяют атрибуты разметки.
