# Поиск и замена

Панель поиска по всему документу: Ctrl/Cmd+F открывает поиск, Ctrl/Cmd+H — поиск с заменой. Совпадения подсвечиваются в тексте,
текущее выделено сильнее; панель считает их («3 / 12») и ходит по ним вперёд и назад.

## Подключение

Не входит в набор по умолчанию: клавиши подключаются в провайдере, панель кладётся рядом с документом.

```tsx
import { EditorProvider, DocumentView, FindReplacePanel, findReplace } from '@inkbrick/react';

<EditorProvider editor={editor} keymap={findReplace.keymap}>
  <FindReplacePanel />
  <DocumentView />
</EditorProvider>;
```

Если у провайдера уже есть свои клавиши, объедините списки: `keymap={[...findReplace.keymap, ...mine]}`. Без `findReplace` в бандл ничего
не попадает.

## Как пользоваться

- `Enter` — следующее совпадение, `Shift+Enter` — предыдущее; после последнего поиск идёт с начала.
- Кнопки `Aa` (учитывать регистр) и `ab` (слова целиком). Запрос — обычный текст, не выражение: `a.b` ищет именно «a.b».
- Если перед открытием выделен текст в одной строке, он подставляется в запрос.
- «Заменить» меняет текущее совпадение и переходит к следующему, «Заменить все» — все совпадения одним шагом undo.
  Форматирование заменяемого текста сохраняется.
- `Esc` закрывает панель, где бы ни был фокус, и выделяет текущее совпадение: его сразу можно править.
- В режиме только чтения панель ищет, но строки замены нет (горячие клавиши редактора там не работают — открывайте через `useFind`).
- Совпадения ищутся в тексте всех блоков, включая код и ячейки таблиц, в том числе в свёрнутых заголовках и закрытых переключателях.
  Формулы и другие объекты внутри строки не совпадают. Больше 5000 совпадений не ищется: список и подсветка остаются быстрыми.
- Виртуальный рендерер (`renderer="virtual"`): блок текущего совпадения отрисовывается и прокручивается в центр окна; подсветка
  есть у блоков, которые сейчас на странице.

## Подсветка

Подсветка использует CSS Custom Highlight API: `::highlight(inkbrick-find)` и `::highlight(inkbrick-find-current)`. Документ при этом
не меняется, лишних элементов в DOM нет. В браузерах без этого API работают переход и замена, но не подсветка.

## Для кода

```ts
import { findMatches, replaceMatches, useFind } from '@inkbrick/react';

const matches = findMatches(editor, 'cat', { caseSensitive: false, wholeWord: true }); // [{ blockId, from, to }]
replaceMatches(editor, matches, 'dog'); // один шаг undo, возвращает число замен

const { controller, state } = useFind(); // внутри <EditorProvider>
controller.open(true, 'cat'); // открыть с заменой и запросом
controller.go(1); // следующее совпадение
controller.replaceAll();
```

Панель — `data-inkbrick-ui="find"`; части: `query`, `status`, `case`, `word`, `prev`, `next`, `close`, `expand`, `replacement`, `replace`,
`replace-all`.
