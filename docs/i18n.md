# Локализация

Все строки интерфейса редактора (подсказки в пустых блоках, toolbar, меню блока, slash-меню, изображения, ошибки
загрузки) лежат в словарях. Из коробки есть **английский** (`en`, по умолчанию) и **русский** (`ru`); свои словари
подключаются без правки библиотеки.

```tsx
<EditorProvider editor={editor} locale="ru">
  …
</EditorProvider>
```

Язык применяется сразу, без перезагрузки: смените `locale` — интерфейс всех блоков и меню перерисуется.
Содержимое документа переводу не подлежит.

## Подключить свой словарь

Способ 1 — глобально, один раз при старте приложения:

```ts
import { registerLocale, type PartialMessages } from '@inkbrick/react';

const de: PartialMessages = {
  'menu.delete': 'Löschen',
  'toolbar.bold.label': 'Fett',
  // … остальное берётся из английского
};

registerLocale('de', de);
// теперь <EditorProvider locale="de"> и getLocales() видят 'de'
```

Способ 2 — только для одного редактора (глобальное состояние не нужно):

```tsx
<EditorProvider editor={editor} locale="de" locales={{ de }}>
  …
</EditorProvider>
```

Способ 3 — точечно поправить отдельные строки выбранного языка:

```tsx
<EditorProvider editor={editor} locale="ru" messages={{ 'menu.delete': 'Убрать' }}>
  …
</EditorProvider>
```

Объекты `locales` и `messages` держите стабильными (вынесите из компонента или оберните в `useMemo`).

### Как выбирается строка

1. Английский словарь `en` — основа: **пропущенных строк не бывает**.
2. Поверх него — словарь языка. Код ищется без учёта регистра: сначала точное совпадение (`pt-BR`), затем базовый
   язык (`pt`). Словари провайдера (`locales`) приоритетнее глобальных. Неизвестный код даёт английский.
3. Поверх всего — `messages`.

Словарь может быть **неполным**: подключайте перевод по мере готовности. Тип `Messages` (полный словарь) требует
каждый ключ, `PartialMessages` — нет. Встроенный русский словарь — полный, это проверяет тест.

### Подстановки

В строках можно использовать `{имя}`: `'image.error.type': 'Неподдерживаемый тип изображения «{type}»'`. Строки, содержащие
подстановки в английском словаре, должны сохранять те же `{имена}` в переводе. Неизвестная подстановка остаётся как есть.

## Ключи

Список — в `packages/react/src/i18n/en.ts` (тип `MessageKey`, TypeScript подскажет допустимые ключи).

| Группа                 | Ключи                                                                                                            |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `editor.hint`          | подсказка в пустом блоке с кареткой («Нажмите «/», чтобы открыть меню»)                                          |
| `block.*`              | подписи списка, кода, заметки, неизвестного блока                                                                |
| `image.*`              | панель и инструменты изображения, статусы (`image.status.*`), ошибки (`image.error.*`)                           |
| `toolbar.*`            | подписи и подсказки кнопок (`toolbar.bold.label`, `toolbar.bold.title`…), поле ссылки                            |
| `handle.*`, `menu.*`   | ручка блока и меню блока                                                                                         |
| `formula.*`, `color.*` | формулы (поле, подсказки, кнопки окошка, вкладки палитры символов `formula.palette.*`) и названия цветов палитры |
| `slash.*`              | заголовок меню, «Ничего не найдено» и для каждого пункта `slash.item.<id>.title`, `.description`, `.keywords`    |

`slash.item.<id>.keywords` — слова для поиска через запятую. Они **добавляются** к английским (`h1`, `todo` находят
пункт на любом языке), поэтому в переводе достаточно перечислить слова своего языка.

Ваши собственные пункты slash-меню и действия меню блока не переводятся автоматически: передавайте им готовые
строки на нужном языке (`useLocale()` подскажет текущий).

## Перевод в своих компонентах

```tsx
import { useT, useLocale } from '@inkbrick/react';

function MyToolbarButton() {
  const t = useT();

  return <button title={t('toolbar.bold.title')}>B</button>;
}
```

`useT()` возвращает `t(key, params?)` текущего редактора; вне провайдера — английский.

## Ошибки загрузки изображений

`onError` в `images` получает исходную ошибку с **английским** сообщением (для логов), а пользователю в блоке
показывается перевод по коду ошибки (`image.error.type`, `image.error.size`, …). Ошибки вашего загрузчика
(`images.upload`) показываются как есть: переводите их сами.

## Песочница

В переключателе песочницы (`EN`, `RU`, `DE`) языки берутся из `getLocales()`: зарегистрированный словарь появляется
в нём сам. `DE` — пример собственного неполного словаря (`apps/sandbox/src/locales/de.ts`). Выбор запоминается в
`localStorage` и в адресе (`?lang=ru`).
