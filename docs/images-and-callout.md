# Изображения и callout

Оба блока встроенные (`block:image`, `block:callout`); их можно заменить своим представлением через `components`,
как любой другой блок.

## Callout

Выделенная заметка с текстом. Props: `tone` — `info` | `warning` | `success` | `danger` (по умолчанию `info`),
`icon` — свой эмодзи (иначе значок по тону). Клик по значку меняет стиль по кругу.

- Создаётся из slash-меню («Callout»), из меню блока («Turn into») или командой `convertBlock`/`insertBlock`.
- Enter продолжает callout с тем же тоном; Enter в пустом — выход в параграф (как у списков и цитат).
- В буфер обмена попадает как `<aside data-callout="тон">`; при вставке такой `<aside>` снова становится callout
  (неизвестный тон заменяется на `info`).

## Изображение

Блок без редактируемого текста (как разделитель): подпись и описание хранятся в props.

| Prop                                        | Значение                                                                                                                              |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `src`                                       | показываемая картинка (после обрезки — файл обрезки); пустой — блок без картинки. **Проверяется схемой**                              |
| `originalSrc`                               | оригинал, из которого сделан файл обрезки; пустой — `src` и есть оригинал. **Проверяется схемой**                                     |
| `alt`                                       | описание для доступности                                                                                                              |
| `caption`                                   | подпись под картинкой                                                                                                                 |
| `showCaption`                               | подпись включена кнопкой (видна и пустой); непустая подпись видна всегда                                                              |
| `width`                                     | ширина в % (10–100, по умолчанию 100)                                                                                                 |
| `align`                                     | `left` / `center` / `right`                                                                                                           |
| `aspect`                                    | форма обрезки: `free`, `circle`, `1:1`, `5:4`, `4:3`, `7:5`, `3:2`, `5:3`, `16:9` и книжные `4:5`, `3:4`, `5:7`, `2:3`, `3:5`, `9:16` |
| `cropX`, `cropY`, `cropWidth`, `cropHeight` | рамка обрезки в % оригинала: левый верхний угол и размер (по умолчанию вся картинка)                                                  |

### Как добавить картинку

- slash-меню («Image») → блок выбора с вкладками **Upload** (кнопка «Upload file», файл можно и бросить на блок) и
  **Link** (поле ссылки); стрелки влево и вправо переключают вкладки;
- **вставка** из буфера (снимок экрана, «копировать изображение») — файл загружается, блок появляется сразу с индикатором;
- **перетаскивание** файла или картинки с сайта в редактор: пока её несут над документом, **линия вставки** (та же, что
  при переносе блока, `data-testid="drop-indicator"`) показывает, куда она встанет — перед блоком под указателем (верхняя
  половина строки) или после него. Картинка с сайта вставляется по адресу (`<img src>` из перетащенного HTML или ссылка
  на файл картинки); адреса чужих серверов сначала идут через `images.rehost`, если он задан;
- вставка HTML с `<img>`/`<figure>` (Google Docs, веб-страницы).

Пустой параграф заменяется картинкой; под картинкой всегда есть блок для продолжения. Картинки из файлов **не вкладываются
в списки**: они встают после блока верхнего уровня.

### Куда сохранять файлы

```tsx
<EditorProvider
  editor={editor}
  images={{
    upload: async (file) => (await api.upload(file)).url, // вернуть адрес http(s) или относительный
    maxInlineBytes: 1_500_000, // предел встраивания, если upload не задан
    rehost: async (url) => (await api.rehost(url)).url, // перезалить чужую картинку при вставке HTML
    acceptedTypes: ['image/png', 'image/jpeg', 'image/webp'],
    onError: (error, file) => toast(String(error)),
  }}
/>
```

Без `upload` картинки **встраиваются в документ** как `data:`-адреса (до `maxInlineBytes`, по умолчанию 1,5 МБ, не больше 1,8 МБ: так картинка проходит и через вставку из HTML);
для больших файлов нужен собственный загрузчик. Адрес, который вернул `upload`, проверяется так же строго, как ввод пользователя.
Если загрузка не удалась при вставке/перетаскивании, пустой блок убирается, а ошибка уходит в `onError`
(при загрузке из блока она показывается в самом блоке).

Вставка блока и запись адреса — **один шаг undo** при любой скорости загрузки (если между ними не было других правок).

### Картинки с чужих серверов при вставке

Вставленный HTML может содержать `<img src="https://…">`. Без настройки такой блок показывает картинку по исходному адресу, и
браузер идёт на чужой сервер: это трекинг-пиксель и утечка IP читателя документа. С `images.rehost` вставка ждёт хук и
вставляет картинку уже по адресу, который он вернул; `null`, небезопасный адрес или ошибка — картинка в документ не
попадает (текст рядом вставляется). Хук не вызывается для фрагментов, скопированных из самого редактора, и для
адресов на тот же origin. Одинаковые адреса в одной вставке обрабатываются один раз.

### Безопасность

Допустимы только `http(s)://…`, относительные пути (`/uploads/a.png`) и растровые `data:image/png|jpeg|gif|webp|avif;base64,…`
(не больше 8 МБ). **SVG, `javascript:`, `blob:`, `//host/…`, `ftp:` отклоняются** — схемой блока (то есть и из кода, и из
буфера, и из сохранённого JSON), а не только интерфейсом. `<img>` рисуется с `referrerPolicy="no-referrer"`,
`loading="lazy"`. Из вставленного HTML принимаются только абсолютные http(s)- и data:-адреса (относительный путь чужого сайта
нам ничего не говорит).

### Обрезка

Окно обрезки — во весь экран (`@inkbrick/image-tools`, грузится отдельным чанком при первом открытии): картинка с рамкой,
которую двигают и тянут за стороны и углы; сверху — меню форм, **Cancel** и **Save**.

- **Формы:** свободная, круг, квадрат и пропорции 5:4, 4:3, 7:5, 3:2, 5:3, 16:9 — у каждой переключатель книжной и
  альбомной ориентации. Выбранная форма сразу даёт самую большую рамку этих пропорций.
- **Два файла.** По **Save** из оригинала делается файл обрезки (холст; у круга — PNG с прозрачными углами) и загружается
  как обычная картинка (`images.upload`, без него — `data:`-адрес). В блок записываются `src` (файл обрезки) и
  `originalSrc` (оригинал) — **один шаг undo**. Повторная обрезка всегда идёт от оригинала.
- Если файл сделать нельзя (картинка с чужого сервера без CORS, слишком большой файл без `upload`, ошибка загрузки), блок
  обрезает оригинал **стилем**: кадр с пропорциями рамки (`data-inkbrick-part="frame"`) показывает её часть.
- **Сразу после добавления** из выбора (файл или ссылка) окно открывается само. Вставка из буфера и перенос файла в текст
  его не открывают. Отключить: `images={{ cropOnAdd: false }}`; тогда окно открывает кнопка **«Crop image»** на панели.
- **Клавиатура:** на рамке стрелки двигают её (с Ctrl — крупнее), Shift со стрелками меняет размер, Enter — Save,
  Esc — Cancel. Tab не выходит из окна.
- Меню **⋯** → «Reset crop» возвращает оригинал, «Download original» сохраняет его.

`toHtml` пишет файл обрезки как обычную картинку (у круга — `border-radius:50%`); обрезку стилем — пропорциями и
положением (`aspect-ratio`, `object-fit: cover`, `object-position`).

### Просмотр во весь экран

Кнопка «View full size» открывает картинку во весь экран: снизу — «назад» и «вперёд» по картинкам документа, масштаб
(«−», уровень — он же «вписать», «+»), сохранение и закрытие. Колесо и щипок меняют масштаб, увеличенную картинку двигают,
двойной щелчок увеличивает вдвое и обратно. Клавиши: стрелки — соседние картинки, «+» и «−» — масштаб, 0 — вписать,
Esc — закрыть; щелчок мимо картинки тоже закрывает.

### Редактирование

При наведении или касании картинки появляется панель: **расположение** (меню: слева, по центру, справа), **подпись**
(включить или убрать вместе с текстом), **обрезка**, **просмотр**, **скачать** (показанную картинку) и **⋯** (описание
`alt`, замена картинки, сброс обрезки, оригинал). Ширину меняют **боковые ручки** на краях картинки: тянут мышью или
пальцем (у картинки по центру — с обеих сторон), с клавиатуры — стрелки по 5 %, Home и End; в документ ширина попадает
одним шагом, когда ручку отпустили.

Поля сохраняются по Enter или при потере фокуса — **один шаг истории**, не на каждую букву; Esc отменяет ввод. Картинка,
которая не загрузилась, показывает ошибку и кнопку «Replace».

В режиме только чтения на панели только просмотр и скачивание, подпись — обычный текст, пустая картинка — «No image».

### Буфер обмена

Копирование отдаёт `<figure><img src alt><figcaption>…</figcaption></figure>`, а в простой текст идёт подпись (или `alt`).
Выделенные блоки без текста подсвечиваются (`data-selected`) и копируются/удаляются вместе с текстом.
