# Изображения и callout

Оба блока встроенные (`block:image`, `block:callout`); их можно заменить своим представлением через `components`,
как любой другой блок.

## Callout

Выделенная заметка с текстом. Props: `tone` — `info` | `warning` | `success` | `danger` (по умолчанию `info`),
`icon` — свой эмодзи (иначе значок по тону). Клик по значку меняет стиль по кругу.

- Создаётся из slash-меню («Callout»), из меню блока («Turn into») или командой `convertBlock`/`insertBlock`.
- Enter продолжает callout с тем же тоном; Enter в пустом — выход в параграф (как у списков и цитат).
- В буфер обмена попадает как `<aside data-callout="тон">`; при вставке такой `<aside>` снова становится callout
  (неизвестный тон заменяется на `info`).

## Изображение

Блок без редактируемого текста (как разделитель): подпись и описание хранятся в props.

| Prop      | Значение                                                                       |
| --------- | ------------------------------------------------------------------------------ |
| `src`     | адрес; пустой — блок без картинки (показывается выбор). **Проверяется схемой** |
| `alt`     | описание для доступности                                                       |
| `caption` | подпись под картинкой                                                          |
| `width`   | ширина в % (10–100, по умолчанию 100)                                          |
| `align`   | `left` / `center` / `right`                                                    |

### Как добавить картинку

- slash-меню («Image») → блок с полем ссылки и кнопкой **Upload**;
- **вставка** из буфера (снимок экрана, «копировать изображение») — файл загружается, блок появляется сразу с индикатором;
- **перетаскивание** файла в редактор — картинка встаёт после блока под указателем;
- вставка HTML с `<img>`/`<figure>` (Google Docs, веб-страницы).

Пустой параграф заменяется картинкой; под картинкой всегда есть блок для продолжения. Картинки из файлов **не вкладываются
в списки**: они встают после блока верхнего уровня.

### Куда сохранять файлы

```tsx
<EditorProvider
  editor={editor}
  images={{
    upload: async (file) => (await api.upload(file)).url, // вернуть адрес http(s) или относительный
    maxInlineBytes: 1_500_000, // предел встраивания, если upload не задан
    acceptedTypes: ['image/png', 'image/jpeg', 'image/webp'],
    onError: (error, file) => toast(String(error)),
  }}
/>
```

Без `upload` картинки **встраиваются в документ** как `data:`-адреса (до `maxInlineBytes`, по умолчанию 1,5 МБ);
для больших файлов нужен собственный загрузчик. Адрес, который вернул `upload`, проверяется так же строго, как ввод пользователя.
Если загрузка не удалась при вставке/перетаскивании, пустой блок убирается, а ошибка уходит в `onError`
(при загрузке из блока она показывается в самом блоке).

Вставка блока и запись адреса — **один шаг undo** (если загрузка быстрая); при долгой загрузке это два шага.

### Безопасность

Допустимы только `http(s)://…`, относительные пути (`/uploads/a.png`) и растровые `data:image/png|jpeg|gif|webp|avif;base64,…`
(не больше 8 МБ). **SVG, `javascript:`, `blob:`, `//host/…`, `ftp:` отклоняются** — схемой блока (то есть и из кода, и из
буфера, и из сохранённого JSON), а не только интерфейсом. `<img>` рисуется с `referrerPolicy="no-referrer"`,
`loading="lazy"`. Из вставленного HTML принимаются только абсолютные http(s)- и data:-адреса (относительный путь чужого сайта
нам ничего не говорит).

### Редактирование

При наведении на картинку появляется панель: выравнивание, ширина (25/50/75/100%), описание (`alt`), замена картинки.
Подпись редактируется под картинкой. Поля сохраняются по Enter или при потере фокуса — **один шаг истории**, не на каждую
букву; Esc отменяет ввод. Картинка, которая не загрузилась, показывает ошибку и кнопку «Replace».

В режиме только чтения панели и поля скрыты, подпись — обычный текст, пустая картинка — «No image».

### Буфер обмена

Копирование отдаёт `<figure><img src alt><figcaption>…</figcaption></figure>`, а в простой текст идёт подпись (или `alt`).
Выделенные блоки без текста подсвечиваются (`data-selected`) и копируются/удаляются вместе с текстом.
