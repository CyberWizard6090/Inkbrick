# Теги `#tag`

Слово с решёткой в тексте — тег. Редактор подсвечивает теги, предлагает их при наборе `#` и сообщает приложению о Ctrl/Cmd+клике.
Тег остаётся **обычным текстом**: в модели документа ничего не меняется, экспорт в HTML, Markdown и текст и вставка работают как раньше.

## Подключение

Не входит в набор по умолчанию: компонент кладётся в провайдер рядом с документом.

```tsx
import { EditorProvider, DocumentView, TagHighlights } from '@inkbrick/react';

<EditorProvider editor={editor}>
  <DocumentView />
  <TagHighlights onTagClick={(tag) => openNotesWithTag(tag)} suggestions={['inbox', 'later']} />
</EditorProvider>;
```

| Свойство      | Что делает                                                                              | По умолчанию |
| ------------- | --------------------------------------------------------------------------------------- | ------------ |
| `onTagClick`  | `(tag, event)`: Ctrl/Cmd+клик по тегу (в `tag` нет `#`); без него клик ничего не делает | —            |
| `suggestions` | дополнительные теги для подсказок (например, теги других заметок), без `#`              | `[]`         |
| `suggest`     | `false` — без подсказок; в режиме только чтения их нет в любом случае                   | `true`       |

## Что считается тегом

- `#` не после буквы, цифры, `_`, `#`, `&` и `/` (поэтому `a#b`, `&#39;` и `/#/route` — не теги), затем буквы любого алфавита,
  цифры, `_`, `-` и `/`: `#idea`, `#идея`, `#to-do`, `#проект/задача` (вложенные теги).
- Из одних цифр (`#123`) — не тег; `#1a` — тег. Дефис и косая черта в конце слова (`#tag-`) в тег не входят.
- Заголовок Markdown `# Заголовок` (решётка и пробел) — не тег.
- В блоках кода и формул, внутри инлайн-кода, ссылок и формул тегов нет.
- Регистр не различается при подсчёте: `#Idea` и `#idea` — один тег, показывается первое написание.

## Подсветка

Теги выделяются CSS Custom Highlight API (`::highlight(inkbrick-tag)`), документ и DOM при этом не меняются; в браузерах без
него подсвечивания нет, остальное работает. Подсвечиваются блоки, которые сейчас на странице (виртуальный рендерер).

## Подсказки при наборе

Пока каретка стоит в наборе `#нач…`, под ней список тегов документа и `suggestions` по убыванию числа упоминаний (до 8,
без тега, набранного целиком): `↑`/`↓` выбирают, `Enter` или `Tab` подставляют тег вместо набранного начала, `Esc` закрывает до
нового `#`; клик мышью тоже подставляет. Клавиши списка перехватываются редактором, пока он открыт, поэтому Enter выбирает тег, а
не делит блок. Список называется «Подсказки тегов» (`tags.suggestions`, en и ru).

## Для кода

```ts
import { collectTags, findTags, blockTags } from '@inkbrick/react';

collectTags(editor); // [{ tag: 'idea', count: 3 }, …] по убыванию числа упоминаний, затем по алфавиту
findTags('a #idea b'); // [{ tag: 'idea', from: 2, to: 7 }] — смещения в тексте
blockTags(editor.document.getBlock(id)!); // то же для блока, без кода, ссылок и формул
```

Части для стилей: список — `data-inkbrick-ui="tag-suggestions"`, пункты — `data-inkbrick-part="item"` (`data-active`, `data-tag`).
