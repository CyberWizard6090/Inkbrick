# Счётчик слов и символов

Строка состояния «Слов: 120 · Символов: 780». Если есть выделение, она показывает и его: «Слов: 12 из 120 · Символов: 64 из 780».
В подсказке (при наведении) — символы без пробелов.

## Подключение

Не входит в набор по умолчанию: компонент кладётся в провайдер рядом с документом, в любое место страницы.

```tsx
import { EditorProvider, DocumentView, WordCount } from '@inkbrick/react';

<EditorProvider editor={editor}>
  <DocumentView />
  <WordCount />
</EditorProvider>;
```

| Свойство    | Что делает                                                                         | По умолчанию |
| ----------- | ---------------------------------------------------------------------------------- | ------------ |
| `code`      | `false` — не считать текст блоков кода                                             | `true`       |
| `delay`     | пауза после правки или выделения перед пересчётом, мс                              | `250`        |
| `className` | свой класс (корень — `data-inkbrick-ui="word-count"`, части `words`, `characters`) | —            |

Пересчёт идёт с задержкой, чтобы на большом документе не считать на каждую букву. Подписи берутся из словаря редактора
(`stats.*`, en и ru).

## Что считается словом и символом

- **Слово** — буквы и цифры подряд. Внутри слова бывают апостроф и дефис (`don't`, `stop-gap` — одно слово), у числа —
  точка и запятая (`3.14`, `1,000`). Пунктуация и тире между словами не считаются. У китайского, японского и тайского, где
  между словами нет пробелов, слова находит `Intl.Segmenter` (без него считается по знаку).
- **Символ** — кодовая точка (эмодзи — один символ), пробелы и переводы строк входят; «без пробелов» их не считает.
- **Формулы** не входят ни в слова, ни в символы. Слова не переходят границу блока: конец одного абзаца и начало другого
  не склеиваются в слово.
- Считаются все блоки документа, в том числе скрытые свёрнутым заголовком и закрытым переключателем: они остаются в документе.
  Ячейки таблицы считаются как обычный текст. Картинки и разделители текста не имеют.

## Для кода

```ts
import {
  countWords,
  countCharacters,
  documentStats,
  selectionStats,
  useWordCount,
} from '@inkbrick/react';

documentStats(editor); // { words, characters, charactersNoSpaces }
documentStats(editor, { code: false }); // без блоков кода
selectionStats(editor, selection); // то же для { from, to, collapsed }; null, если выделение свёрнуто
countWords('one two'); // 2

const { document, selection } = useWordCount({ delay: 100 }); // внутри <EditorProvider>; selection — null без выделения
```
