# Формулы

Формулы пишутся на LaTeX и бывают двух видов: **блок** `block:formula` (отдельной строкой) и **встроенные** в
текст. Рисует их Temml — библиотека превращает LaTeX в MathML, который отображает сам браузер (без шрифтов и
CSS-фреймворков). Temml (≈ 480 КБ) подгружается при появлении первой формулы: документы без формул её не платят.

## Как вставить

| Что                 | Как                                                                                                                                            |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Блок-формула        | `/formula` в slash-меню или `$$ ` в начале пустого абзаца. Поле ввода открывается сразу                                                        |
| Встроенная, шорткат | `$код$`: закрывающий `$` превращает набранное в формулу. Код не может начинаться или кончаться пробелом («$5 и $6» остаётся ценой)             |
| Встроенная, окошко  | `Ctrl/Cmd+Shift+M` (курсор или выделенный текст) или кнопка Σ в toolbar. Выделенный текст становится заготовкой кода                           |
| Править             | Клик по формуле. У встроенной в окошке есть кнопка «Удалить»; у блока правка закрывается по `Ctrl/Cmd+Enter` или потере фокуса, `Esc` отменяет |

В окошке и в блоке виден живой предпросмотр; ошибка разбора показывается под полем, а в документе формула остаётся
исходным кодом. `Backspace` сразу после встроенной формулы удаляет её целиком.

## Палитра символов

Под полем кода в блоке и в окошке встроенной формулы есть палитра быстрой вставки: вкладки и сетка кнопок. Нажатие
вставляет **код LaTeX** в позицию курсора (подсказка кнопки показывает код), а фокус остаётся в поле — формулу можно
продолжать набирать с клавиатуры. Кнопки доступны и с клавиатуры (`Tab`).

| Вкладка     | Что внутри                                                                                                                                                   |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Функции     | `sin`, `cos`, `tan`, `cot`, `sec`, `csc`, `arcsin`…, `sinh`, `cosh`, `tanh`, `log`, `ln`, `exp`, `lim`, `max`, `min`, `det`…                                 |
| Конструкции | дробь, корень, степень и индекс, `∑`, `∏`, `∫`, `∬`, `∮`, биномиальный коэффициент, скобки, модуль, вектор, черта, шляпка, матрицы, система (`cases`), `	ext` |
| Греческие   | строчные и заглавные буквы, варианты (`arepsilon`, `arphi`…)                                                                                                 |
| Операторы   | `± ∓ × ÷ · ∘ ⊕ ⊗ ∞ ∂ ∇`, многоточия, градус, `ℓ`, `ℏ`…                                                                                                       |
| Отношения   | `≠ ≈ ≡ ∼ ≅ ∝ ≤ ≥ ≪ ≫ ∈ ∉ ⊂ ⊆ ⊃ ⊇ ∣ ∥ ⊥`                                                                                                                      |
| Стрелки     | `→ ← ↔ ⇒ ⇐ ⇔ ↦ ⟶ ⟹ ⇌ ∴ ∵`                                                                                                                                    |
| Множества   | `∅ ℕ ℤ ℚ ℝ ℂ ∪ ∩ ∖ ∀ ∃ ¬ ∧ ∨ ⊢ ⊨`                                                                                                                            |

Шаблоны с аргументами (`\sin(⌖)`, `\sqrt{⌖}`) ставят курсор на место аргумента, а если в поле выделен текст — **оборачивают**
его: `a+b` + «√» → `\sqrt{a+b}`. Команды без аргумента заканчиваются пробелом, чтобы следующая буква не слиплась с командой
(`lpha x`, а не `lphax`). Наборы лежат в `packages/react/src/formula/symbols.ts` (`SYMBOL_CATEGORIES`); тест проверяет, что
каждый шаблон принимает Temml. Переводы — `formula.palette.*`. Атрибуты: `formula-palette`, `formula-palette-tab`
(`data-category`, `data-active`), `formula-palette-grid`, `formula-symbol` (`data-snippet`).

## Как это хранится

- Блок: `{ flavour: 'block:formula', props: { latex: '\\frac{a}{b}' } }`. Текста у блока нет.
- Встроенная: **один символ-объект** `U+FFFC` (`FORMULA_CHAR`) с атрибутом `formula: 'код LaTeX'`:
  `{ insert: '￼', attributes: { formula: 'E=mc^2' } }`. Благодаря этому смещения, удаление, undo, разделение и
  склейка блоков работают без особых случаев: формула — обычный символ.
- Предел длины — 5000 символов (`MAX_FORMULA_LENGTH`). Пустая формула не вставляется.
- Текст, набранный сразу после формулы, не наследует атрибут `formula`.

Команды движка: `insertFormula` (`{ blockId, from, to, latex }`), правка кода — `setInlineAttributes` с
`{ formula: '…' }` на диапазоне из одного символа-объекта (атрибут нельзя ставить на обычный текст и снимать:
для удаления используйте `deleteText`).

## Подключить другой «движок» формул

```tsx
import katex from 'katex';
import 'katex/dist/katex.min.css';

const render: FormulaRenderer = (latex, target, { display }) => {
  katex.render(latex, target, { displayMode: display, throwOnError: true, trust: false });
};

<EditorProvider editor={editor} formulaRenderer={render}>
  …
</EditorProvider>;
```

- `FormulaRenderer` — `(latex, target, { display }) => void | Promise<void>`; при ошибке функция бросает исключение.
- `formulaRenderer={false}` — показывать только исходный код.
- Результат вставляется в страницу как есть, а LaTeX приходит из документа: включайте безопасные режимы библиотеки
  (`trust: false`).
- Готовые результаты кэшируются, поэтому перерисовка блока на каждое нажатие клавиши не мигает. Держите функцию
  стабильной: её смена перерисовывает все формулы.

## Встроенная формула в DOM

Встроенная формула — нередактируемый `<span data-inkbrick-formula data-latex="…" data-state="…">`; сама формула лежит
в его **теневом корне** (поэтому её внутренний текст не попадает в `Range.toString()`, и смещения курсора равны смещениям
модели). Снаружи доступны:

- `[data-inkbrick-formula]` и состояния `data-state="loading|ready|error|source|fallback"`;
- `::part(math)` — сам MathML, например `[data-inkbrick-formula]::part(math) { font-size: 1.1em }`.

Блок-формула: `data-inkbrick-block="formula"`, части `formula-display`, `formula-render` (`data-state`), `formula-editor`,
`formula-source`, `formula-preview`, `formula-error`, `formula-hint`, `formula-empty`. Окошко встроенной формулы:
`data-inkbrick-ui="formula-popover"`.

## Экспорт

| Формат   | Встроенная                                 | Блок                                      |
| -------- | ------------------------------------------ | ----------------------------------------- |
| Markdown | `$код$` (если в коде есть `$` — `\(код\)`) | `$$` на отдельных строках                 |
| HTML     | `<span class="math inline">\(код\)</span>` | `<div class="math display">\[код\]</div>` |
| Текст    | исходный LaTeX                             | исходный LaTeX                            |

HTML в стиле pandoc: KaTeX auto-render и MathJax находят такие элементы сами. В буфер обмена формулы кладутся так же
(текстовая версия — LaTeX), а внутри Inkbrick копируются точно, вместе с атрибутом.
